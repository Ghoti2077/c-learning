# 📝 代码版本账（每版记一笔）

> [!quote] 为什么要记这个（2026-11-19 他自己的原话）
> 「我最后我东补补，西补补，把它补回来了……我觉得以后我每一次写完代码自检的时候都要记录一次，这样就能知道我每一版到底错在哪里，改了哪里。不然就像现在，我只记得我比较大的错误，小的错误我都已经记不太清了。」

道理跟 `git log` 一样：**只记大错 = 下次还会掉进同一个坑，因为你想不起它是怎么来的。**
记的代价是每版两行；不记的代价是每次重来一遍。

## 模板（复制这几行，改了就填，没改就写「没改」）

```text
### 题目 PXXXX  标题  （日期）
| 版本 | 这版我改了什么 | 跑出来什么 | 真因（一句话） |
|---|---|---|---|
| v1 |  |  |  |
| v2 |  |  |  |
| v3 |  |  |  |
```

**规矩三条：**
1. **提交前先写 vN 那一行**，别等 AC 了再补 —— AC 之后人的记忆会自动把过程抹平。
2. 「真因」写不出来就先空着，标 `?`，等我或者明天自己补 —— 空着也比不写强。
3. 只错一次的小错也要记（一个字母、一个下标），小错才是反复出问题的那些。

## 格式示例（**真记录在每题自己的页面里**）

| 版本 | 这版我改了什么 | 跑出来什么 | 真因（一句话） |
|---|---|---|---|
| v1 | 拍脑袋开了个巨大数组 | 跑不起来 | 数组太大，栈装不下 |
| v2 | 换成变量定长度 | 后面全错 | 那版不初始化，读到垃圾值 |
| v3 | 开到刚好够大并清 0 | AC | 空格子清成 0 了 |

> [!tip] 2026-11-19 起改了做法
> 每题的完整版本账**写在那一题自己的页面里**（`05-实战与考试/题目/`，从 [[🎯 刷题总表]] 进去），
> 这页只留**模板和规矩**，不再按题记 —— 否则同一件事记两处，以后不知道信哪个。
> 想看真实范例：[[P5732 杨辉三角]]。

## 记在哪
- **每题一页**：`05-实战与考试/题目/<题号> <标题>.md`，在 [[🎯 刷题总表]] 里点内链进去。
- 写完顺手把这题「真因」里值得长期记的知识点，抄一行进 `📌 抽查池（间隔复习）.md`。
