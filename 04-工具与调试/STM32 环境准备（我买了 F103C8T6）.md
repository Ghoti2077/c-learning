# STM32 环境准备（我买的板子：F103C8T6）

> **一句话**：**C8T6 属于 STM32F1（HAL1 层）→ 只下 `STM32CubeMX`（一代），`STM32CubeMX2` 完全用不上**（MX2 只支持 C5 及以后的新系列）。

---

## 1. 我的板子是什么

**STM32F103C8T6** —— 就是俗称的「**蓝板 / Blue Pill**」（最小系统板）。

| 项目 | 参数 |
|---|---|
| 内核 | **ARM Cortex-M3**，72 MHz |
| Flash | 64 KB（有些板子上其实是 128 KB 的 C8B/CB 芯片，代码一样用） |
| RAM | 20 KB |
| 封装 | LQFP48 |
| 系列 | **STM32F1** → 属于 **HAL1** 层 → **一代 CubeMX 支持** ✅ |

（⚠️ 待确认：我买的具体是"最小系统板"还是别的型号板卡 —— 如果包装上写的不是 C8T6 最小系统板，回头告诉我。）

## 2. 该下哪个 ST 工具（重要）

| | **STM32CubeMX**（一代） | STM32CubeMX2 |
|---|---|---|
| 支持芯片 | **所有 MCU/MPU，除了 C5** ← **我的板子在这边** ✅ | 只有 STM32C5 及以后 |
| 软件层 | HAL1 | HAL2 |
| 配置文件 | `.ioc` | `.ioc2`（**两代不互通**） |
| IDE 支持 | Keil MDK、IAR、CubeIDE | 只有 IAR / CMake / CubeIDE（**不支持 Keil**） |
| 我要不要 | **要**，版本 **6.18.1 Latest** | **不要** |

> **结论：只下 `STM32CubeMX` 6.18.1。** MX2 是给 C5 新芯片用的，我的板子在那边的列表里根本选不到。

## 5. 除了 CubeMX，还要准备什么

| 东西 | 作用 | 备注 |
|---|---|---|
| **STM32CubeF1 固件包** | CubeMX 生成代码时要用的库（HAL 库 + 例程） | **在 CubeMX 里在线安装**（Help → Manage embedded software packages），不用单独下 |
| **ST-Link V2 下载器**（小 U 盘似的那个） | 把程序**烧进芯片**、还能在线调试 | 蓝板一般买的时候会配；没有的话用 **USB 转串口（USB-TTL）** 走串口下载 |
| **STM32CubeProgrammer** | 烧录/读芯片的官方软件 | ST 官网免费下；用 Keil/CubeIDE 时通常不用它 |
| **IDE（选一个）** | 写代码 + 编译 + 下载 | 常见三条路：**Keil MDK**（教程最多）、**STM32CubeIDE**（免费，内含 CubeMX 功能）、**CLion + OpenOCD**（我本机已有 CLion，但嵌入式配置偏麻烦） |

## 4. 最省事的新手路线（待定，等我看教程再选）

1. **CubeIDE 路线**：一个软件全包（配置 + 编译 + 下载 + 调试）→ 装的东西最少
2. **CubeMX + Keil 路线**：教程最多，但要装两个软件，Keil 是商业软件（有社区版限制）
3. **CubeMX + CLion/VS Code 路线**：适合以后想用现代编辑器的人，但配置步骤多
