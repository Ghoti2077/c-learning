## 1. 型号拆解：STM32F103C8T6

> 依据：DS5319 Rev 18 第 **107 页** `Ordering information scheme`（不是我从网上背的，是这本 PDF 里原文）

| 段 | 值 | 含义（原文） | 可选项 |
|---|---|---|---|
| `STM32` | 家族 | Arm-based 32-bit microcontroller | — |
| `F` | 产品类型 | **General-purpose**（通用/主流型，课件上叫 Mainstream，手册写 General-purpose） | — |
| `103` | 子系列 | **Performance line**（F1 里的性能型） | — |
| `C` | 引脚数 | **48 pins** | T=36 / C=48 / R=64 / V=100 |
| `8` | Flash | **64 Kbytes** | 8=64KB / B=128KB |
| `T` | 封装 | **LQFP** | H=BGA / I=UFBGA / T=LQFP / U=VFQFPN |
| `6` | 温度 | **-40 ~ 85 ℃** 工业级 | 7 = -40 ~ 105 ℃ |

**读法总原则**：每一段都是"菜单里挑一个"。所以 `C8T6` 不是乱码，是
**48 脚 + 64K Flash + LQFP 封装 + 工业温度** 四个勾选项连在一起。

> [!note]- 为什么一份手册能管好几种芯片？
> DS5319 的封面写的是 **STM32F103x8 / STM32F103xB** —— 这里的 `x` 是通配符，
> 意思是 C8、R8、V8、T8、RB、CB、VB、TB 全在这一本里。
> 所以"中等密度"（Medium-density）= 64K 或 128K Flash 的这一批 F103，
> 不是某一个具体型号。查手册时先看封面通配型号，确认你要的那颗在里面。

## 2. 两本手册的分工（这是最容易搞混的）

| | 数据手册 Datasheet（DS5319，英文，116 页） | 参考手册 Reference Manual（RM0008，中文，一千多页） |
|---|---|---|
| 回答什么 | **这颗芯片有什么、能不能干这个活** | **怎么让它干这个活** |
| 内容 | 引脚定义、电气参数（电压/电流/频率）、封装尺寸、时钟树、外设清单、订货型号 | 每个外设的寄存器、每一位的含义、工作模式、时序 |
| 我会查什么 | 这个脚能不能输出、耐不耐 5V、Flash 多大、用哪几个脚 | TIM2 的 PWM 怎么配、USART 波特率寄存器怎么算 |
| 生活类比 | 电器的**铭牌 + 参数表**（220V、60W、多重） | 电器的**使用说明书**（哪个按钮干什么） |

> 顺序别搞反：**先用数据手册确认"这个脚/这个外设存在"，再去参考手册查"怎么用"。**

## 3. 引脚定义表（Table 5，第 28~32 页）怎么读

表头 7 列，从左到右：

1. **引脚号** —— ⚠️ 最坑的一列：它是**按封装分列的**（LFBGA100 / UFBGA100 / **LQFP48** / TFBGA64 / LQFP64 / LQFP100 / VFQFPN36）。
   **C8T6 是 LQFP48，只认 LQFP48 那一列的编号**，别照第一列（那是 BGA100 的球号）。
2. **引脚名称** —— `PA13` = 端口 A 的第 13 号；`PC13` 同理。
3. **类型** —— `I/O` 双向；`S` 电源/地（VDD/VSS/VBAT）；`I` 输入。
4. **I/O 电平** —— `FT` = **5V tolerant（耐 5V）**；空白 = 只能 3.3V。
5. **主功能** —— 复位后这个脚的"本职身份"。
6. **默认复用功能**（Default）—— 交给外设用时，默认分到哪个外设，如 `USART1_TX / TIM1_CH2 / ADC12_IN9`。
7. **重定义功能**（Remap）—— 另一套可选的分配，要软件开 AFIO 重映射才行。

例子（原文核对过）：**25 脚 PA13 → 类型 I/O、电平 FT、主功能 `JTMS/SWDIO`、无默认复用**。

## 4. 三个实战坑

> [!warning]- 坑 1：PA13 / PA14 是下载口，别拿去点灯
> `PA13 = JTMS/SWDIO`，`PA14 = JTCK/SWCLK` —— 这就是 ST-Link / DAP 下载程序用的两根线。
> 拿它们做普通 IO，程序一跑起来就**把下载口拆了**，下次下载直接连不上（要靠按住复位或 BOOT0 才能救回来）。

> [!warning]- 坑 2：FT 不是"万能 5V"
> FT = 5V 容忍，指的是**输入**能扛 5V；输出高电平仍然是 3.3V 左右。
> 而且 VBAT/VDD/VDDA/BOOT0/NRST 这些脚**没有 FT**，绝对不许灌 5V。

> [!warning]- 坑 3：别把 BGA 的脚号当 LQFP48 的
> 表里同一个功能会对应 7 个不同的编号，7 列里只有一列是你的封装。

## 5. 自测（我自己答，答完标 🟢）

1. `STM32F103RBT6` 是多少脚、多大 Flash、什么封装？（用第 1 节的表推）
2. 一个 5V 输出的传感器信号要接进单片机，接哪个脚最安全？判断依据是哪一列？
3. 想知道 TIM3 的 PWM 寄存器怎么配，翻哪一本？想确认 PA6 能不能输出 TIM3_CH1，翻哪一本？

> 答案在第 1、3 节的表里，推完再对。

### 答案与思路（2026-10-18 我答完后补）

**1. STM32F103RBT6** → `R`=64 脚、`B`=128KB Flash、`T`=LQFP、`6`=-40~85℃。
我一开始只答出前三段，温度段漏了 —— 其实它和我手上这颗 **C8T6 的 `6` 是同一个温度档**，不用另记。

**2. 5V 输出的传感器接哪个脚**
- 第一步：先看**信号方向**。传感器输出 → 单片机接收，所以单片机这个脚是**输入**。
- 第二步：只有"当输入"时才谈"扛不扛得住对方的电压"。
- 第三步：看**第 4 列 I/O 电平**，找写着 `FT` 的脚（手册脚注 2 原文：`FT = 5 V tolerant`）。
- 实例（原文核对）：`PA9`、`PA10` 是 `FT`；`PA0~PA7` 那一片带 `ADC12_INx` 的脚，这一列是空的，**按只能 3.3V 对待**。
- 补一句：FT 只管输入，**输出高电平还是 3.3V**，不能拿 FT 脚去输出 5V。

**3. 两本手册怎么选 —— 一个口诀**
> 问"**能不能**"→ 翻数据手册；问"**怎么配**"→ 翻参考手册。

- "TIM3 的 PWM 寄存器怎么配" → **参考手册（中文 RM0008）**。
- "PA6 能不能输出 TIM3_CH1" → **数据手册 Table 5**。原文 PA6 那行：默认复用 `SPI1_MISO / ADC12_IN6 / TIM3_CH1` → **能，而且属于默认复用，不用开重映射**。

**一个容易混的点**：`TIM3_CH1` 除了 PA6，重映射后还能落到别的脚上 —— 所以"外设名"和"引脚"不是一一对应，必须查表。
