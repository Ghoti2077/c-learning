## P003 1.1 STM32 的基本信息（14:24）— 已用语音转写核对

四问大纲：
> 1. STM32 是什么？ 2. 扮演什么角色、怎么用？ 3. 理解 STM32 型号的含义 4. 课程的参考资料

**① 名字拆三段（他的原话）**：
- **ST** = STMicroelectronics（意法半导体）—— 意大利 **SGS** + 法国**汤姆森**半导体合并，各取首字母；中文"意法"也来自两国首字
- **M** = Microcontroller，微控制器（就是"单片机"）
- **32** = 32 位
- 合起来：**ST 公司生产的 32 位单片机的一个统称**

**② STM32 干什么用（他的例子）**：一个学长的毕业设计 —— **智能手环**
`MAX30100`（心率+血氧）、`MPU-6050`（陀螺仪+加速度）、`DS3231`（实时时钟）、`DS18B20`（温度）、一块显示屏
→ 这些模块靠中间那块黑板上的 **STM32** 用 C 程序串起来 → **STM32 是"管理者 / 控制器"**

**③ 型号怎么来的**：把芯片**迎着光转一下**，激光雕刻的文字前两行就是型号 `STM32F103C8T6`。

**④ 型号含义（手机类比 + 系列树）**

| 段 | 含义 |
|---|---|
| ST | 品牌（意法半导体） |
| M32 | 产品类型：32 位微控制器 |
| **F103** | 产品系列 |
| **C8T6** | 规格型号（见下表） |

系列树（他的原话）：
- 总五大系列：**G 通用 / F 主流 / H 高性能 / L 低功耗 / W 无线**
- **F103 属于 F 系列"主流型"**（主打性价比）
- F 下面：F0 / F1 / F2 / F3 / F4 / F7 → **F103 属于 F1**（Cortex-M3 内核，**72MHz**）
- F1 内部再分：F100 / F101 / F102 / **F103** / F105 / F107（用法基本相同）

`C8T6` 四段（课件原文）：

| 段 | 含义 | 本芯片 |
|---|---|---|
| **C** | 引脚数量：T=36 / **C=48** / R=64 / V=100 / Z=144 | **48 脚** |
| **8** | Flash 容量：4=16K / 6=32K / **8=64K** / B=128K / C=256K…最大 1024K | **64KB** |
| **T** | 封装：H=BGA / I=UFBGA / **T=LQFP** / U=UFQFPN | **LQFP**（引脚从四边伸出来；BGA 是背面一颗颗小圆点） |
| **6** | 温度：**6 = -40~85℃** / 7 = -40~105℃ | **-40~85℃** |

**⑤ 两本手册分工（他打的比方）**
- **数据手册 DS5319** = 芯片的**规格书** → 性能指标、参数（电压范围、输出功率、温度…）
- **参考手册 RM0008** = 芯片的**说明书** → 每个模块怎么用、原理、怎么编程
- 资料在他的百度网盘 `标准库 / 第一章第一节`，两本手册都在里面（中文版一般够用）

> [!note] 转写的两处口误（别记错）
> ASR 把 `F103` 听成 `F100X`、把温度说成"零下45度" —— 真实是 **F103** 和 **-40℃**。

## P004 1.2 引脚分布（10:14）— 已用语音转写核对

四问大纲：
> 1. 在手册中找到单片机的引脚分布图 2. 引脚的编号规则 3. 特殊引脚的功能和作用 4. 常规引脚的命名规则

**① 找图**：打开 **DS5319** → 目录第三部分 **`Pinouts and Pin Description`** → 一张图对应一种封装；型号给的是 `C`(48脚) + `T`(LQFP) → **LQFP48** → 就是**第 8 张图**。

**② 编号规则**：芯片上有个**黑色圆点**，**离圆点最近的引脚 = 1 脚**，然后**逆时针**递增 1→48。（手册的图上也有个黑圆点，规则一样）

**③ 特殊引脚（5 个）**

| 引脚 | 作用 | 他补充的话 |
|---|---|---|
| **VDD** | 电源正，接 3.3V | 冷知识：老电路用 VCC/GND，STM32 用 VDD/VSS —— 因为 **MOS 管**里 `D` = Drain 漏极（接正）、`S` = Source 源极（接负） |
| **VSS** | 地，接 0V | 同上 |
| **NRST** | 复位，接复位按钮（按下 → **程序从头开始执行**） | 最小系统板上那颗按钮 |
| **VBAT** | 备用电池（纽扣电池） | 主板断电后靠它维持一部分功能；板上只有引脚、**没装电池** |
| **BOOT0** | 选择启动模式 | 板上有个**跳帽**，拨左/拨右 = BOOT0 接低/高 |

**④ 常规引脚命名**：`P` + 组字母 + 编号
- GPIOA：PA0 ~ PA15（16 个）
- GPIOB：PB0 ~ PB15（16 个）
- GPIOC：**PC13 / PC14 / PC15**（只有 3 个）
- GPIOD：**PD0 / PD1**（只有 2 个）

> [!warning] 他专门强调的一点
> **同一组的编号在芯片上并不连续**：PA0~PA7 是连着的，然后断开，PA8 在另一侧；PA13 后又断，PA14 在别的位置。
> **看引脚位置只能查表/看分布图，不能"顺着数"。**（E04 笔记里那条"编号不是排排坐"就是这个）

## P005 2.1 GPIO 的四种输出模式（32:53）— 已用语音转写核对

**开场类比**：人体结构图 —— **大脑只管思考，做事得靠眼睛/鼻子/嘴巴/腿/手**。
→ 打开 **DS5319 第 11 页**那张"内部结构框图"：**CPU = 大脑，片上外设 = 器官**，GPIO 就是"手"。

**8 种工作模式一分为二**（课件）：

| 输出（4 种，本节讲） | 输入（4 种，留到 2.4） |
|---|---|
| 通用输出推挽 / 通用输出开漏 | 输入上拉 / 输入下拉 |
| 复用输出推挽 / 复用输出开漏 | 输入浮空 / 模拟模式 |

> 他明确说：**这一节只讲左边 4 种**，右边 4 种是后面的内容。

### ① 推挽 / 开漏（他的原话逻辑）

- **推挽 = push + pull**：**推** = 向外推电流，**挽** = 从外面往里拉电流
  （⚠️ ASR 把它听成 "POUR"，**真实英文是 pull**）
- **推**：上面 **P-MOS 通、N-MOS 断** → 引脚经上管接 **VDD(3.3V)** → 电流往外流
- **挽**：上面 P-MOS 断、下面 **N-MOS 通** → 引脚经下管接 **VSS(0V)** → 电流往里流
- **两个管子交替导通，绝不能同时通** —— 他亲口说的理由：**同时通就是 VDD 直接连 VSS，短路**（这段和你在图上看到的一模一样，你上周答对了）
- 推挽写 **0 → 0V**，写 **1 → 3.3V**（"跟常识符合，好记"）

### ② 开漏为什么叫"开漏"

- **开漏 = 上面那个 P-MOS 永远断开** → 于是下面 N-MOS 的**漏极(D)就一直悬空/开路** → 故称"开漏"
- 写 **0**：下管通 → 引脚接 VSS → **0V**（和推挽一模一样）
- 写 **1**：两个管子**全断** → 引脚**悬空**，外面加多大电压电流都恒为 0
  → 用欧姆定律 `R = U / I`，**I=0 → R = 无穷大 → 高阻态**
- 这就是开漏的命门：**写 1 不是"输出高电平"，而是"松手不管"**（要靠外面接上拉电阻把电平拉上去）

### ③ 通用 / 复用

- **通用**：CPU **直接**往"输出数据寄存器"写 0/1 → 经输出控制电路 → 控制两个 MOS → 控制引脚
  例：`PA9` 接一颗 LED，写 0 灭、写 1 亮
- **复用**：控制信号**来自别的片上外设**（不是 CPU 直接写）→ **外设"接管"这根引脚**
  例：`PA9` 接**串口模块的发送脚(TX)**，程序让串口发 "Hello" → **串口模块接管 PA9**，自己去产生高低变化的波形
- 所以四种模式就拆成两个问题：**谁在推（CPU / 外设）× 怎么推（推挽 / 开漏）**

> [!important] 视频 2.1 **没有**讲的三件事（我上次那篇 E05 补的，属于手册知识）
> 1. **重映射**（换一扇门）—— 视频里完全没提
> 2. **PC13 为什么必须开漏** —— 这是数据手册里的电气限制，不是这节的内容（但结论对，你上次也答对了）
> 3. **三档速度** —— 那是 2.2 的内容

## P006 2.2 IO 的最大输出速度（10:25）—— 完整内容（whisper 转写）

> [!note] 2026-10-26 他的自评（按"答对≠懂了"新规矩）
> 回了 **1懂 / 2半 / 3会算但单位不清 / 4半 / 5半**，具体卡点：
> - **#2**：「上升的到底是什么？」→ 补讲：**上升的是引脚上的电压**（0V→3.3V），纵轴是电压、横轴是时间
> - **#3**：「会算但 1ns 是多少秒」→ 补讲：1ns = 10⁻⁹ 秒（十亿分之一）；秒→毫秒→微秒→纳秒 每级 ÷1000
> - **#4**：「是谁在读这个电压？」→ 补讲：**引脚另一端接的器件**（另一颗芯片的输入脚/模块/电脑串口）；输入脚有高低门限，卡在中间既不算高也不算低 → 读出来是随机的
> - **#5**：「EMI 是什么」→ 补讲：**电磁干扰**（Electromagnetic Interference）；边沿越陡 = 电流变化越快 = 像小电台往外发射，干扰旁边的电路；选档的正确说法是「按**这条线上信号实际要跑的最高速率**挑最小档」，不是「器件需要的最小频率」
> 讲完待他再自评一次才算过。


四问大纲：
> 1. 什么是 IO 的最大输出速度 2. **上升时间、下降时间和保持时间**的概念 3. 什么限制了最大输出速度 4. 应该如何选择

1. **定义**：不断交替写 0/写 1。速度慢时波形标准；一直加速，**到某个频率波形就"没法输出有效电压"** → 那个频率就是最大输出速度。讨论时**假定用推挽输出**。
2. **三个概念**：理想情况电压瞬间跳变；现实是**上升沿/下降沿是斜坡**。
   - 电压 0→3.3V 的时间 = **上升时间**
   - 3.3V→0 的时间 = **下降时间**
   - 中间输出有效电压的时间 = **保持时间**
3. **谁限制了速度**：**上升时间和下降时间**。速度越快 → 两个斜坡越靠越近 → **保持时间变 0** → 没有有效电压。
   想又快又正常？**把上升/下降时间做短（斜坡更陡）** → 最大输出速度就变大。
4. **三档怎么来的（课件原文）**：

   | 档 | 上升 | 保持(最短) | 下降 | 周期 | 倒数 |
   |---|---|---|---|---|---|
   | 低速 | 125ns | 250ns | 125ns | **500ns** | **2MHz** |
   | 中速 | 25ns | 50ns | 25ns | **100ns** | **10MHz** |
   | 高速 | 5ns | 10ns | 5ns | **20ns** | **50MHz** |

5. **怎么选**：**选满足要求的最小档**。为什么不都选 50MHz？
   - **功耗增加**（电池供电要在意）
   - **EMI**：边沿太陡，会干扰别的电子元件
6. **三个实例（原话）**：
   - 驱动 LED：**人眼临界闪烁频率 45.8Hz**，交流电 50Hz 看着都不闪；一般 LED 闪烁不超过 100Hz → **2MHz 足够**
   - **英飞凌 TLE5012B**（GMR 磁编码器）：SPI(SSC) 波特率 **8Mbps → 选 10MHz**
   - 板上 **USB 2.0 全速 12Mbps** → **10MHz 不够，只能选 50MHz**

## P007 2.3 LED 闪灯实验（42:34）— 已用语音转写核对

> 完整讲义见 [[E06 2.3 LED闪灯实验（讲义·已核视频）]]，这里只记"他讲了什么"。

- **灯接法**：`3.3V → 限流电阻 → LED → PC13`，**低电平点亮**
- LED 电流 **2~10mA**（他取约 **5mA**；画面实测 **2.70mA**）
- 讲了**两种接法**：推挽接法 / 开漏接法 → 本板是**开漏接法**
- **定稿参数（他亲口）**：**`GPIO_Mode_Out_OD` 通用输出开漏** + **`GPIO_Speed_2MHz`**
  - 开漏的理由："因为我们 LED 使用的是一个开漏的接法"
  - 2MHz 的理由："LED 一般不超过 100Hz，2 兆 = 两百万，选一个最小的就可以了"
- **结构体 = 菜单**比喻；`= {0}` 初值他特别强调："不付初值有的时候会产生意想不到的错误"
- **不需要理解的固定写法**：`RCC_APB2PeriphClockCmd`（"本来后面才学，现在提前拿来"）
- **坑（他现场演示）**：`Delay()` 不是标准库 → 不写 `#include "delay.h"` 报错，加上就消失

## P008 2.4 四种输入模式（15:37）— 已用语音转写核对

- **输入模式干什么**：读外面的电压是高还是低，**转成 0/1 存进"输入数据寄存器"**，程序再去读
- **输入电路的走线（他按框图讲）**：
  `引脚 → 保护二极管（防静电高压）→ 上拉电阻 / 下拉电阻 → 施密特触发器（把电压整形成干净的 0/1）→ 输入数据寄存器`
- **三种模式就是"这两个电阻使能哪个"**：
  | 模式 | 意思 |
  |---|---|
  | **输入上拉** | 使能上拉电阻 → 引脚**什么都不接时默认读到高电平** |
  | **输入下拉** | 使能下拉电阻 → 悬空时**默认低电平** |
  | **输入浮空** | 两个电阻都不使能 → 电平完全由外面决定 |
  | 模拟模式 | 数字部分断开，直接送 ADC（这一集一带而过，ADC 章再讲） |
- 标准库宏名：`GPIO_Mode_IPU` / `GPIO_Mode_IPD` / `GPIO_Mode_IN_FLOATING` / `GPIO_Mode_AIN`

## P009 2.5 按钮实验（20:33）— 已用语音转写核对

- **目标**：**按下按钮 → LED 亮；松开 → LED 灭**
- **接线**：按钮**一端接 PA1、另一端接地**
- **配成输入上拉模式**，于是：
  - **松开** → 上拉电阻把 PA1 拉高 → 读到 **1**
  - **按下** → PA1 直接接地 → 读到 **0**
- **代码核心**：
  ```c
  if (GPIO_ReadInputDataBit(GPIOA, GPIO_Pin_1) == Bit_RESET)  // == 0 → 按钮按下
  { /* 点亮 LED */ }
  else                                                       // 松开
  { /* 熄灭 LED */ }
  ```
- 正好把 2.4 的"上拉/下拉"用上了：**按钮按下读到什么，取决于你配的是上拉还是下拉**
