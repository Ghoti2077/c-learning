## 1. 实验目标

**让板载 LED 一闪一闪**。这是本套课**第一集真正写代码**的课。

## 2. 先搞清楚这颗灯怎么接的（他花了 10 分钟讲这个）

- 他原话："这里标注了 PC13……**说明这盏灯是连接在我们单片机的 PC13 引脚上的**"
- 电路：**3.3V → 限流电阻 → LED → PC13** → 所以 **PC13 拉低（写 0）→ 灯亮；写 1 → 灯灭**
- **LED 需要 2~10mA 的电流**（他取约 **5mA**；画面实测 **2.70mA**），必须串**限流电阻**
- 他讲了**两种接法**：**推挽接法** / **开漏接法** —— 本板是**开漏接法**

> [!important] 这就是"为什么开漏"的最终答案（他亲口说的）
> "因为我们 LED 使用的是一个**开漏的接法**，所以这个地方我们应当选择**开漏**"
> 再因为"我们是**用 CPU 直接往寄存器写值**" → **通用**
> → 结论：**GPIO_Mode_Out_OD（通用输出开漏）**

## 3. 两个参数怎么定

| 参数 | 视频里的选择 | 他的理由（原话） |
|---|---|---|
| **模式** | **`GPIO_Mode_Out_OD`** | 灯是开漏接法 + CPU 直接写寄存器 → 通用输出开漏 |
| **速度** | **`GPIO_Speed_2MHz`** | "LED 工作速度比较慢，一般**不超过 100Hz**；2 兆 = 两百万，跟 100Hz 比起来快得多，**选一个最小的就可以了**" |

> [!note] 关于画面里出现过的 `Out_PP` + `50MHz`
> 抽帧确实抓到过一帧写着 `GPIO_Mode_Out_PP` / `GPIO_Speed_50MHz` —— 那是他**边讲边打字时的中间态**，
> 讲完之后定稿的是 **`Out_OD` + `2MHz`**。**按定稿的写。**
> 另外数据手册对 PC13/14/15 这组脚写了"输出速度不得超过 2MHz"，所以 2MHz 也是唯一安全的选择。

## 4. 完整代码（定稿版）

```c
#include "stm32f10x.h"
#include "delay.h"          /* Delay() 不是标准库的，是山羊自己提供的 */

int main(void)
{
    /* 第 1 步：给 GPIOC 开时钟 */
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);

    /* 第 2 步：配置 PC13 */
    GPIO_InitTypeDef GPIO_InitStructure = {0};   /* 必须先清 0 */
    GPIO_InitStructure.GPIO_Pin   = GPIO_Pin_13;
    GPIO_InitStructure.GPIO_Mode  = GPIO_Mode_Out_OD;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_2MHz;
    GPIO_Init(GPIOC, &GPIO_InitStructure);

    /* 第 3 步：循环闪 */
    while (1)
    {
        GPIO_WriteBit(GPIOC, GPIO_Pin_13, Bit_RESET);   /* 写 0 = 拉低 = 亮 */
        Delay(100);                                     /* 100 毫秒 */
        GPIO_WriteBit(GPIOC, GPIO_Pin_13, Bit_SET);     /* 写 1 = 松手 = 灭 */
        Delay(100);
    }
}
```

## 5. 逐行讲（按他讲课的顺序）

| 行                                         | 他怎么说                                                                                                                                                                                                                                                                                             |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `#include "stm32f10x.h"`                  | 标准库的总头，`GPIO_InitTypeDef` 这些都在里面                                                                                                                                                                                                                                                                 |
| `RCC_APB2PeriphClockCmd(..., ENABLE)`     | **"给 GPIOC 这只手供血"** —— 时钟 = 心跳，器官没血不干活。<br>他明确说："这个接口本来后面才学，**现在提前拿出来，是固定写法，先不用理解**"（时钟树那章再讲）                                                                                                                                                                                                    |
| `GPIO_InitTypeDef ... = {0}`              | 结构体 = **一张登记表**（或"点菜的菜单"）：把"要什么"填进格子，函数照着表执行。<br>**关于 `{0}` 的准确说法**：这个结构体正好 **3 个格子**（Pin/Speed/Mode），**三个都填了的话，不加 `{0}` 也能正常工作**（已实测编译+逻辑正确）。但**强烈建议养成加的习惯** —— 库里别的结构体（如 `TIM_TimeBaseInitTypeDef`、`USART_InitTypeDef`）格子比常填的多，**没填的格子若不初始化就是垃圾值**，那才会出"意想不到的错误"。课程原话"必须给初值"说的是这个习惯，不是这三格的硬要求。 |
| `.GPIO_Pin = GPIO_Pin_13`                 | 引脚编号：PC13 → 编号 **13**（范围 `GPIO_Pin_0` ~ `GPIO_Pin_15`）                                                                                                                                                                                                                                           |
| `.GPIO_Speed = GPIO_Speed_2MHz`           | 三档：`GPIO_Speed_2MHz` / `10MHz` / `50MHz`                                                                                                                                                                                                                                                         |
| `.GPIO_Mode = GPIO_Mode_Out_OD`           | 8 种模式里选一种。**PP = Push-Pull；OD = Open-Drain；AF = Alternate（复用）**                                                                                                                                                                                                                                  |
| `GPIO_Init(GPIOC, &GPIO_InitStructure)`   | 把菜单交上去。两个参数：**端口号** + **结构体指针**（`&` 取地址）                                                                                                                                                                                                                                                         |
| `GPIO_WriteBit(port, pin, Bit_SET/RESET)` | 往输出数据寄存器写 1/0。**`Bit_SET` = 写 1 = 灭；`Bit_RESET` = 写 0 = 亮**（低电平点亮）                                                                                                                                                                                                                               |
| `Delay(100)`                              | 延时的单位是**毫秒**，填 100 = 100ms                                                                                                                                                                                                                                                                       |
| `while (1)`                               | 条件恒为真 → 一直循环 → 一直闪                                                                                                                                                                                                                                                                               |

## 6. 他的实操流程（照着做就行）

1. 下载**模板工程** → 重命名成自己的工程名
2. 左边树形结构：`default → User → main.c`，双击打开（**代码就写在这里面**）
3. 先写测试代码验证灯：`GPIO_WriteBit(..., Bit_SET)` 一行、`Bit_RESET` 一行，编译下载看灯
4. 测试完**把这两行注释掉**（他演示了"注释"按钮：绿色双下划线那个）
5. 在 `while` 循环里写正式的闪烁代码
6. **编译**（左上第二个按钮）→ 必须看到 **`0 Errors`** 才算成功
7. **下载**（两个上下箭头的按钮）→ 看到三行：`Programming Done` / `Verify OK` / `Finish` = 成功
8. **按板子上的复位键** → 灯开始闪

## 7. 三个必踩的坑

1. **不开时钟 → 后面写什么寄存器都不动**（`RCC_APB2PeriphClockCmd` 少写这行）
2. **`Delay()` 不是标准库的** → 不写 `#include "delay.h"` 会报错。**他现场演示了这个报错，然后补上头文件就消失了**
3. **`while(1)` 少了分号 / 写成 `while(1);`** —— 后者是空循环 = 死循环，灯一动不动

## 8. 自测题（先答再看答案）

1. 参数为什么是 **`Bit_RESET` 亮、`Bit_SET` 灭**？（从"灯接着 3.3V"这个接法讲）
2. 为什么"LED 不超过 100Hz"就能选最小档 2MHz？（用 2.2 学的"上升/下降/保持时间"说）
3. `RCC_APB2PeriphClockCmd` 这行如果整行删掉，会怎样？**编译**会不会报错？

> [!question]- 参考答案（先自己答完再点开）
> 1. 灯是 `3.3V → 电阻 → LED → PC13`。写 0 时引脚接 VSS(0V)，灯两端有 3.3V 压差 → 有电流 → 亮；写 1 时引脚 3.3V，灯两端同电位 → 无电流 → 灭。
> 2. 2MHz 的周期是 500ns（125+250+125），50Hz~100Hz 的周期是 10~20ms，**比 500ns 慢 2 万倍以上**，波形远远不会失真；再快就是浪费电 + EMI。
> 3. **编译不会报错**（函数是合法调用），灯只是不亮 —— 这类"编译通过但硬件不动"的错最难查。这正是"开时钟"这一步的意义。

## ❓ FAQ（他 2026-10-26 亲口问过的）

### Q1：开漏模式下，3.3V 的电压"漏下来"不是还会烧坏那只 3mA 小开关吗？

**不会。关键是"电流走哪条路"。**

- 那只小开关在 **VDD 那一侧**，是给 P-MOS 送电的通道 → **只有"往外供出电流"时它才带电**。
- **开漏把上管永久断开** → 那条路根本不通 → 小开关**不带电流**，不发热、不损坏。
- 灯的实际电流路径绕开了它：
  `外部 3.3V → 510Ω → LED → PC13 引脚 → N-MOS → VSS(地)`

**比喻：小开关是"往外送水的水泵"。开漏 = 你把水泵关了。现在的水是从外面倒进来、再从后门（地）流走的，根本不经过水泵 —— 泵当然不会烧。**

手册原话方向：PC13/14/15 **"不能当作电流源"**（must not be used as current sources，例如驱动 LED）—— **禁止的是"供出"这个方向，"灌入"（sink）不在禁止之列**。另有两条限制：输出速度 ≤ 2MHz、负载 ≤ 30pF —— 我们的用法（开漏 + 灌 2.7mA + 2MHz 档）正好压在限制之内。

### Q2：那如果模式写成推挽、又写 1，会怎样？

在 `3.3V → 510Ω → LED → PC13` 这个接法里：引脚也是 3.3V → **两端没压差 → 没电流 → 也不烧**（灯也不亮）。
**但一旦灯接反成 `PC13 → 510Ω → LED → GND`，推挽写 1 就是"往外供电"，电流必须穿过小开关 → 这就危险了。**
**所以开漏不是"多此一举"，是从根上断掉这个可能。**

### Q3：`GPIO_ReadOutputDataBit`（接口4）跟 `GPIO_ReadInputDataBit`（接口3）有什么区别？

| 接口 | 读的是 | 人话 |
|---|---|---|
| `GPIO_ReadOutputDataBit` | **输出数据寄存器 ODR** | 读**我刚才命令它做什么** |
| `GPIO_ReadInputDataBit` | **输入数据寄存器 IDR**（引脚实际电平） | 读**它现在真的怎样** |

- **推挽**模式下两者基本一致（说啥是啥）。
- **开漏**模式下**可以不一致**：你写 1 = 命令"松手"，但引脚实际是高阻，真实电平由**外部电路**决定 → 这时候真值只能看 `ReadInputDataBit`。
- **一句话：ODR 是"命令"，IDR 是"现实"。**
