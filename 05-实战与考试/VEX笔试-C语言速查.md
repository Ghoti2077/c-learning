# VEX 线下笔试 · C 语言速查

> 依据：本库 L01~L40（鹏哥 B站 45 集），进度见 `_交接.md`。
> 用法：考前 30 分钟只读「一、必背 20 条」和「三、我踩过的坑」。

## 一、必背 20 条（已学范围内，笔试高频）

**输入输出**

1. `printf("%d", x)` 输出整数；`%f` 浮点、`%c` 字符、`%s` 字符串、`%lf` 读 double。
2. `scanf("%d", &x)` —— **变量前必须加 `&`**（取地址），漏了就崩。
3. `scanf` 的格式串里**不要写 `\n`**，写了会卡住等输入。

**类型与内存**

4. `sizeof` 是**运算符**（不是函数），算的是**字节数**；`sizeof(x)` 和 `sizeof x` 都对。
5. 常见大小：`char`=1、`short`=2、`int`=4、`float`=4、`double`=8 字节。
6. `int` 范围 −2³¹ ~ 2³¹−1（约 ±21 亿），**超了变负数**——因为没有第 32 位放符号了。
7. 负数在内存里是**补码**：`-1` = `11111111`；`unsigned` 只是"换一种读法"，位不变。
8. 1 字节 = 8 比特；一个比特只有 0/1 两种状态。

**运算**

9. **整数除法会截断**：`7/2 == 3`，不是 3.5。要小数就写 `7/2.0` 或 `1.0/i`。
10. `%` 取余只能用于**整数**，`7.5 % 2` 编译不过。
11. `++i` 先加再用，`i++` 先用再加（单独成句时没区别，混在表达式里才有）。
12. 优先级要记的三个：`!` > 算术 > 关系 > `&&` > `||` > 赋值；**不确定就加括号**。
13. `=` 是赋值，`==` 才是比较。`if (x = 5)` 永远为真——经典送分/送命题。

**分支**

14. `if` 只管**紧跟的一条语句**；要管多条必须加 `{}`。
15. `else` 跟**最近的、还没配对的 `if`** 配对（悬垂 else）。
16. `switch` 的 `case` 后面必须是**常量**，且**不写 `break` 会穿透**到下一个 case。

**循环**

17. 三种循环：`while` 先判断；`do-while` **至少执行一次**（结尾有分号）；`for` 适合已知次数。
18. `break` 跳出**整个循环**；`continue` 只跳过**本次**，回到条件判断。
19. ⚠️ `while` 里用 `continue` 时，**步进必须写在 `continue` 之前**，否则死循环。

**数组**

20. 下标**从 0 开始**，`a[10]` 的合法下标是 0~9；数组在内存里**连续存放**。
21. 初始化 `int a[5] = {1,2};` → 剩下三个自动补 **0**。
22. 元素个数 = `sizeof(a) / sizeof(a[0])`。

## 二、还没学（笔试可能直接考，先认脸）

不是让你现在学，是**别在考场上愣住**。

**函数**（未学）
```c
int add(int a, int b);        // 声明（原型）
int add(int a, int b) { ... } // 定义
```
认得：返回类型 + 函数名 + 参数表；`return` 只能带回一个值；`void` 表示不返回。

**指针**（未学）
```c
int x = 10;
int *p = &x;   // p 存的是 x 的地址
*p = 20;       // 通过 p 改 x
```
认得：`*` 是"解引用"（顺着地址找过去），`&` 是"取地址"。`sizeof(int*)` 在 64 位机上是 **8**。

**位运算**（欠账里挂着）
```
&  按位与     |  按位或     ^  异或     ~  取反
<< 左移（×2）  >> 右移（÷2）
```
经典题：`x & 1` 判断奇偶；`x << 1` 等于 ×2；`x & (x-1)` 清掉最低位的 1。

**结构体**（未学）
```c
struct Point { int x; int y; };
struct Point p = {1, 2};
p.x = 3;      // 用 . 访问成员
```

## 三、我踩过的坑（本库易错点清单里出现过的）

- `main` 写成全局变量 / 少分号 → 报一堆看不懂的错，**先看第一个错误行号**。
- VS 的 IntelliSense（E0065 / E3148）和真编译器（C2054）报的**不是一回事**，以编译器为准。
- `scanf` 不加 `&`。
- `while` 里 `continue` 忘了步进 → 死循环。
- 整数除法求平均值 → 结果被截断，要写成 `1.0 * sum / n`。
- `int` 溢出变负数 —— 阶乘、累加最容易撞。

## 四、考前 10 分钟只背这 6 句

1. `scanf` 要 `&`；整数除法会截断。
2. `=` 不是 `==`。
3. `int` 21 亿封顶，超了变负。
4. `if` 只管一条语句，多条要加 `{}`。
5. `switch` 不写 `break` 会穿透。
6. 数组下标从 0 开始，个数 = `sizeof(a)/sizeof(a[0])`。

## 五、笔试答题套路

- **看代码求输出**：拿纸一行一行代值，别心算。循环跑 3 轮就写 3 行。
- **改错题**：先找**分号、括号、`=`/`==`、`&`** 这四处，占 80%。
- **手写代码题**：先写 `#include <stdio.h>` + `int main()`，框架分先拿到。
- 实在不会：把题目里的变量和循环**照抄**一遍，写清每一步的值，过程分能捞。
