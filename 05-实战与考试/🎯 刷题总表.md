## 📏 规矩（我自己定的）

1. 每题**先自己写 15 分钟**，不许先看题解。卡住把代码 + 报错发出去，只要方向不要答案。
2. 编译完**先数警告**，不是 0 就当成错误处理（命令行 gcc 默认不查，必须带 `-Wall`）。
3. **提交前先在自己那页写一行版本账**（改了啥 / 跑出来啥 / 真因）。
4. 题面读不准就截图，只让人帮读题面，不帮写。

## 🧭 两个平台的区别

| 平台 | 要写的是什么 | 练的是 |
|---|---|---|
| **洛谷** | 完整程序（`#include` + `int main()` + `scanf`/`printf`） | 读输入 → 算 → 打印 |
| **力扣** | 一枚「零件」函数（`return` 结果），平台自己有 main | 参数进、结果出 |
