## 二、底盘：差速就是把摇杆拆成两个数

```cpp
void chassis_control(){
    float straight = Controller.Axis3.position();   // 前后 -100~100
    float turn     = Controller.Axis1.position();   // 转向

    if(straight < 5 && straight > -5) straight = 0;   // 死区
    if(turn     < 5 && turn     > -5) turn     = 0;

    float left_output  = straight - turn;
    if(left_output  > 100.0) left_output  =  100.0;
    if(left_output  < -100.0)left_output  = -100.0;
    float right_output = straight + turn;
    if(right_output > 100.0) right_output =  100.0;
    if(right_output < -100.0)right_output = -100.0;

    left_drive.spin(fwd, left_output, pct);
    right_drive.spin(fwd, right_output, pct);
}
```

> [!note] 三行推演（这是理解差速的唯一方式）
> | straight | turn | left | right | 车怎么走 |
> |---|---|---|---|---|
> | 60 | 0 | 60 | 60 | 直行 |
> | 0 | 50 | -50 | 50 | 原地左转 |
> | 60 | 50 | 10 | 110→100 | 边走边左转 |
>
> **铁律：转弯时内侧轮慢、外侧轮快。**

> [!warning] 两个必须做的检查
> 1. **死区不能只写一个条件**：`if(turn < 5)` 会把 `-20` 也吃掉，整个后退没了。必须 `turn < 5 && turn > -5`。
> 2. **合成后会超过 ±100**：`60 + 50 = 110`，`pct` 的范围是 0~100，所以夹限幅不能省。

## 三、里程：电机角度 → 英寸

```cpp
const double IN_PER_DEG = 3.14159266 * 2.75 * (43.0/50.0)/360.0;  // = 0.020639 英寸/度
double dist_in = 0;   // 累计里程（全局，display 线程要读）

void update_distance(){
    static double last_l = 0;   // 上次左轮读数
    static double last_r = 0;   // 上次右轮读数

    double l = left_motor_1.position(degrees);
    double r = right_motor_1.position(degrees);

    dist_in += ((l - last_l) + (r - last_r))/2.0 * IN_PER_DEG;
    last_l = l;
    last_r = r;
}
```

> [!tip] `static` 是什么
> 普通局部变量 = **每次进门发一张新白纸**，出门就扔。
> `static` = **墙上钉着的黑板**，只有第一次进门擦干净，之后每次进来还留着上次的字。
> 没它的话 `l - last_l` 会变成 `l - 0`，里程指数级爆炸。

> [!important] 换算来源（都是估的，实验室要量）
> 轮径 2.75 in → 一圈 8.6394 in → 齿轮比 43/50 → 电机一圈 7.4299 in → 每度 0.020639 in → **走 1 米电机约转 1907 度**。

## 四、最高温：十台一台台比

```cpp
double hottest(){
    double m = right_motor_1.temperature(celsius);
    double j = right_motor_2.temperature(celsius);  if(m<j)m=j;
    j = right_motor_3.temperature(celsius);         if(m<j)m=j;
    j = right_motor_4.temperature(celsius);         if(m<j)m=j;
    j = right_motor_5.temperature(celsius);         if(m<j)m=j;
    j = left_motor_1.temperature(celsius);          if(m<j)m=j;
    j = left_motor_2.temperature(celsius);          if(m<j)m=j;
    j = left_motor_3.temperature(celsius);          if(m<j)m=j;
    j = left_motor_4.temperature(celsius);          if(m<j)m=j;
    j = left_motor_5.temperature(celsius);          if(m<j)m=j;
    return m;
}
```

> [!warning] 两个坑
> 1. **`temperature()` 不写参数拿到的是百分比，不是摄氏度**。必须 `temperature(celsius)`。
> 2. **`motor_group.temperature()` 只返回组里第一台**，不管另外四台。所以必须自己比。
> 3. 第一版漏了 `right_motor_5`（复制粘贴时写成了第二个 `right_motor_4`）——**编译不报错**，5 号最烫时返回的是错误的值。

## 五、屏幕：三行数据

```cpp
void display(){
    while(true){
        Controller.Screen.clearScreen();
        Controller.Screen.setCursor(1,1);
        Controller.Screen.print("T: %.0fC", hottest());

        Controller.Screen.setCursor(2,1);
        Controller.Screen.print("D: %.1fin", dist_in);

        Controller.Screen.setCursor(3,1);
        Controller.Screen.print("H:%.0f", imu.heading());

        wait(50,msec);
    }
}
```

> [!note] 屏幕三件套
> - `clearScreen()` = 橡皮，擦整屏
> - `setCursor(行, 列)` = 把笔挪到指定位置（**行列都从 1 开始**）
> - `print(格式, 参数)` = printf 那一套
> - 顺序：先擦 → 再挪笔 → 再写。不擦的话 `12.3` 变 `8.5` 会显示成 `8.53`

## 六、线程：PPT 第二次培训那块

> [!abstract] 一句话
> **线程 = 让你不用站着等。**

- **顺序**：烧水 → 站壶前面等 → 再洗碗
- **并发**（一个人）：按开关就走开洗碗，水在烧、碗在洗，**但同一瞬间只有一双手**
- **并行**（两个人）：真同时

> [!warning] 纠正一个常见误解
> VEX 官方规格：`VEXos Processor: One Cortex A9` / `User Processor: One Cortex A9`。
> **用户程序只占一颗核**，另一颗归 VEXos 管设备通信。
> 所以你写的多线程是**并发（轮换）不是并行**——**开线程不会让程序变快**，只是让程序别傻等。

`wait(10, msec)` 的准确含义：**我自己往后站 10 毫秒，让别人插队，顺便让自己别跑那么疯。**
不是「分给别人 10 毫秒」——你没权力分配。而且 VEXos 是抢占式调度，你不让位它也会硬抢，只是大家都变卡。

## 七、今晚踩过的坑（全是编译不报错的）

| 坑 | 现象 | 为什么编译不报 |
|---|---|---|
| 代码敲进 `main` 的裸 `{ }` 里 | 能跑、bin 变大，但 `chassis_control()` 是空的 | 函数里写 `{ }` 块完全合法 |
| `right_motor_4` 写了两遍 | 少比一台电机 | 语法没问题 |
| `Controller.Screen.clearScreen;` 少了括号 | 屏幕永不擦除 | 「提到函数名」是合法表达式 |
| `display()` 调用它下面才定义的 `hottest()` / `dist_in` | `not declared in this scope` | ← 这个**会**报错 |

> [!important] 一条规则管住后两个
> **括号 = 叫它干活；没括号 = 只提到名字。**
> `clearScreen()` 是拿橡皮擦；`clearScreen` 只是提了橡皮一句。
> 反过来 `thread display_thread(display)` 故意不加括号——那是把活交给线程，加了就在 main 里当场执行了。

> [!important] 另一条规则管住顺序
> **先数据 → 再工具 → 最后 main。**
> 编译器从上往下一行行读，用到之前必须见过它。
