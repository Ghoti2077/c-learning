# P5720 一尺之棰

- 🔗 题目链接：https://www.luogu.com.cn/problem/P5720
- 练什么：**while 循环**：每次减半，问几次到 1（第一天就算一天，容易多算/少算一次）
- 状态：☑ 2026-11-11 逻辑对
- ⬅ 回去：[[🎯 刷题总表]]


## 题面要点（已核对）

第一天长 a，**从第二天开始**每天除 2 向下取整，问第几天变成 1；样例 `100 → 7`；数据 `1 ≤ a ≤ 10^9`。

## 我的代码

```c
int num = 1;
while (length > 1) { length /= 2; num++; }
```

- **完全正确**，本地 `100 → 7` 与样例一致，`-Wall -Wextra` 0 警告。
- `num = 1` 从 1 起，正好对上「第一天就算一天」这个坑。
- `10^9 < 2^31-1 = 2147483647` → **int 够用**，不用 long long。

## 只提风格

1. `int length = 0;` 的 0 是废初值 → 直接 `int length;`
2. `num` 改叫 `day`
3. `length = length / 2` → `length /= 2`
4. 缩进统一

## 教学点

**初值要么有意义（如 P1085 的 `max = 0` 兼默认答案），要么别给。**
