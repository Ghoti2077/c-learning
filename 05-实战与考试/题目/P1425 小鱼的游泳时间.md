# P1425 小鱼的游泳时间

## 📄 题目

**题目描述**：小鱼从 $a$ 时 $b$ 分一直游泳到当天的 $c$ 时 $d$ 分（$24$ 小时制），请你帮她算一下，这天一共游了多少时间。

**输入格式**：一行内四个整数，以空格隔开，分别表示 $a, b, c, d$。

**输出格式**：一行内输出两个整数 $e$ 和 $f$，用空格间隔，依次表示一共游了多少小时多少分钟。其中表示分钟的整数 $f$ 应该小于 $60$。

**数据范围**：$0\le a,c \le 24$，$0\le b,d \le 60$，且结束时间一定晚于开始时间。

> 完整题面（含样例）：https://www.luogu.com.cn/problem/P1425

- 练什么：时间差：分减分，**不够减要向前借 60**

## 我的思路

写的时候我不确定分够不够减，干脆写了 `if` 判一下：

```c
if (minute2 - minute1 <= 0) { ... } else { ... }
```

## 复盘

- **两个分支内容完全一样**，都是：
  ```c
  tot = (hour2 - hour1) * 60 - (minute1 - minute2);
  ```
  所以 `if/else` 是死代码，等于没写。
- **但式子是对的**：用 200000 组随机用例跟「全换成分钟再相减」对拍，0 处不一致。
  原因是 `-(minute1 - minute2)` ≡ `+(minute2 - minute1)`，借 60 藏在符号里了。
- 两种精简：A 删掉 `if/else` 保留原式；B 全换分钟 `(hour2*60+minute2) - (hour1*60+minute1)`。
- **我选择不改**（提交完不想动），不算欠账。
- 抽查池：C20（符号等价）/ C21（为什么统一单位就不用借位）。
