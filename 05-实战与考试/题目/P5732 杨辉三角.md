# P5732 杨辉三角

- 🔗 题目链接：https://www.luogu.com.cn/problem/P5732
- 练什么：**二维数组**：`a[i][j] = a[i-1][j-1] + a[i-1][j]`
- 状态：☑ 2026-11-19 AC（提交过很多版）
- ⬅ 回去：[[🎯 刷题总表]]


## 题面（已核对）

「P5732 【深基5.习7】杨辉三角」，给出 `n (1 ≤ n ≤ 20)`，输出前 n 行。

## 版本账（我实际提交了很多次）

| 版本 | 这版我改了什么 | 跑出来什么 | 真因 |
|---|---|---|---|
| v1 | `int a[10000][10000]` | **根本输出不来** | 1 亿个 int = **381 MB**，全摆在栈上，栈装不下 |
| v2 | 改成 `int a[n][n]`（变长数组） | 能出结果，但从中间某行开始**全是错的数** | VLA **不能初始化**；`a[i-1][i]` 那格从没被清过 → 读到垃圾值，一代错代代错 |
| v3 | 换成 `int a[1000][1000] = {0}` | **AC** | 空格子被清成 0，跨行读到的那个「不存在的列」也成了 0 |

## 我的思路

先把每行第 0 列填 1、第 1 列填行号（`a[i][1] = i`），再按「上一行左右两格相加」推下去。

## AC 的代码（原样）

```c
#include<stdio.h>
int main()
{
    int n;
    scanf("%d",&n);
    int a[1000][1000]={0};
    int i;
    for(i=0;i<n;i++)
    {
        a[i][0]=1;
        a[i][1]=i;
    }

    printf("1\n");
    for(i=1;i<n;i++)
    {printf("%d ",a[i][0]);
        int j;
        for(j=1;j<=i;j++)
        {
            a[i][j]=a[i-1][j-1]+a[i-1][j];
            printf("%d ",a[i][j]);
        }
     printf("\n");
    }
    return 0;
}
```

## 复盘（两个坑，都已实测）

### ① 3.8 MB 的数组摆在栈上

`int a[1000][1000]` = 4,000,000 字节 ≈ 3.8 MB，写在 `main` 里就是放栈上。Windows 栈默认 1 MB：

```text
rc=-1073741571      ← 0xC00000FD，STATUS_STACK_OVERFLOW
```

洛谷是 Linux、栈 8 MB，才过得去。本题 n ≤ 20，**正解是 `int a[21][21] = {0};`**（我改成这个跑过，输出一模一样）。

### ② 有一个「隐藏依赖」

`j` 最大取到 `i`，这时右边是 `a[i-1][i]` —— 上一行根本没有第 i 列。它能算出 1，纯粹因为开头 `={0}` 把那片格子清成了 0。
**那个 `={0}` 不是可有可无的，是这步的地基。** 删了就冒莫名其妙的数。
