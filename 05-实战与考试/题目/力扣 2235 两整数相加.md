# 力扣 2235 两整数相加

## 📄 题目

**题目描述**：给你两个整数 `num1` 和 `num2`，返回这两个整数的和。

**示例 1**：

```text
输入：num1 = 12, num2 = 5
输出：17
解释：12 + 5 = 17
```

**示例 2**：

```text
输入：num1 = -10, num2 = 4
输出：-6
```

**提示**：`-100 <= num1, num2 <= 100`

**注意**：力扣只收「零件」——实现 `int sum(int num1, int num2)` 就行，**不写 `main`**。

> 完整题面：https://leetcode.cn/problems/add-two-integers/

- 练什么：力扣只交「零件」函数：参数进、`return` 出，没有 `main`、没有 `scanf/printf`
- 状态：✅ 2026-11-11 过（中间撞了两次报错）
- ⬅ 回去：[[🎯 刷题总表]]


## 这两次报错记在这里

### 第一次：`redefinition of 'main'`

我按平时的习惯写了完整程序（`#include` + `int main()` + `scanf` + `printf` + `return 0;`），判题报：

```text
Line 18: Char 5: error: redefinition of 'main'
```

报错指的 `int main(int argc, char *argv[])` **根本不是我写的**。

**真因**：力扣判题时把平台自己的 `main` 拼在我的代码后面 → 一个程序两个 `main`。

### 第二次：`expected declaration specifiers ... before string constant`

我听完第一条，把 `main` 连花括号一起删了，只剩四行裸放在文件最外层 → 又报错。

**真因**：文件最外层只许放声明/定义，`scanf` / `printf` / `return` 必须待在函数的花括号里。花括号是工作台，工具得放台上。

## 我自己想通的那句话

> 平台自己会传参、自己会打印，我只要写那个小函数。

```c
int sum(int num1, int num2)
{
    /* 只填这里 */
}
```

`scanf` / `printf` / `int num1, num2;` 全部删掉。
