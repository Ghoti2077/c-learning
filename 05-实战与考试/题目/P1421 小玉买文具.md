# P1421 小玉买文具

## 📄 题目

**题目描述**：班主任给小玉一个任务，到文具店里买尽量多的签字笔。已知一只签字笔的价格是 $1$ 元 $9$ 角，而班主任给小玉的钱是 $a$ 元 $b$ 角，小玉想知道，她最多能买多少只签字笔呢。

**输入格式**：只有一行两个整数，分别表示 $a$ 和 $b$。

**输出格式**：一行一个整数，表示小玉最多能买多少只签字笔。

**数据范围**：$0 \leq a \leq 10^4$，$0 \leq b \leq 9$。

> 完整题面（含样例）：https://www.luogu.com.cn/problem/P1421

- 练什么：单位换算：元/角换成分，整除求最多买几支（整数除法会「吃掉」小数，正好体会一下）
- 状态：☑ 2026-11-11 AC
- ⬅ 回去：[[🎯 刷题总表]]


## 我的思路

元、角两种单位混着不好算，先全换成分（最小的那个单位），再除一支笔的价钱。

## 我写的（第一版，原样留档）

```c
int tot_jiao; tot_jiao = yuan * 10 + jiao;
int sum;      sum = (tot_jiao / 19);
printf("%d", sum);
```

## 复盘

- 三处「臃肿」：① 两个只喂一次的中转变量各占两行 ② `(tot_jiao/19)` 括号多余 ③ 变量名 `sum` 名不符实，装的是「几支笔」不是「和」。
- 两条习惯：`printf` 结尾加 `\n`；`10` 和 `19` 是「魔法数」，现阶段不用管。
- 我实际没重写（已经提交了）。精简版留在这里备用：

```c
int total = yuan * 10 + jiao;
printf("%d\n", total / 19);
```
