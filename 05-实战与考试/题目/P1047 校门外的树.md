# P1047 [NOIP 2005 普及组] 校门外的树

## 📄 题目

**题目描述**：马路上有一排树，数轴上每个整数点 $0,1,2,\dots,l$ 都种有一棵树。现在要把 $m$ 个区域（由起始点和终止点给出，**包括端点处的树**）中的树移走，区域之间可能有重合。问移走后还剩多少棵树。

**输入格式**：第一行两个整数 $l$（马路长度）和 $m$（区域数目）。接下来 $m$ 行，每行两个整数 $u, v$，表示一个区域的起始点和终止点坐标。

**输出格式**：一行一个整数，表示剩余的树木数量。

**数据范围**：$1 \leq l \leq 10^4$，$1 \leq m \leq 100$，$0 \leq u \leq v \leq l$。

> 完整题面（含样例）：https://www.luogu.com.cn/problem/P1047

- 练什么：**标记数组**（数组当「记录表」）+ 区间覆盖

## 我一开始想的（走不通那条路）

把 m 个区间存进 `a[m][2]`，然后两两比较「有没有交集、有交集怎么并」。
这条路能做，但重叠可能好几层、谁先谁后还得排 —— 会一直卡在边角上。

**换个表示法就没了**：不存区间，改成给每一米记一句「这棵树还在吗」。胶带压过来就改成「没了」，压十次也还是「没了」。

## 版本账

| 版本 | 这版我改了什么 | 跑出来什么 | 真因 |
|---|---|---|---|
| v1 | `int a[m][2];` 写在 `scanf` **之前** | **Segmentation fault（signal 11）** | `m` 还没装数就被拿去定数组大小 → 尺寸是垃圾值 → 栈要不到空间 |
| v2 | 把 `scanf` 挪上去 | **MLE（内存超限）** | `scanf("%d%d",&m,&num)` 两个变量**读反了**：`m` 装的是路长（≤10000），`num` 才是区域数 → 循环 `i<m` 读 10000 行区域，可输入只有 3 行 → 从第 4 次起 `scanf` 空手而归，`a[i]` 从没被写过 → 垃圾值当区间终点，`for(j=a[i][0]; j<=a[i][1]; j++)` 一路越界写 → 内存写爆 |
| v3 | 把 `&m,&num` 换成 `&num,&m`，初始化跟路长走，重新数一遍 1 | **298 ✅ AC** | 变量顺序对了 |

### 两次报错其实是同一个病

v1 和 v2 都是「**数组尺寸 / 数组内容取决于一个还没准备好的数**」：
- v1 尺寸不确定 → 分配失败 → 崩
- v2 内容没读进来 → 循环终点是垃圾 → 越界写 → 内存爆

**双变量的 `scanf` 之后先打一行 `printf` 看清哪个是哪个**，这类错能省掉一半。

## AC 的代码（原样）

```c
#include<stdio.h>
int main()
{
    int b[20000]={0};
    int i;
    for(i=0;i<=20000;i++)
    {
        b[i]=1;
    }
    int num,m;//num是长度，m是区域数
    scanf("%d%d",&num,&m);
     int a[m][2];
    int trees = 0;
    for(i=0;i<m;i++)
    {
        scanf("%d%d",&a[i][0],&a[i][1]);
    }
    for(i=0;i<m;i++)
    {
        int j;
        for(j=a[i][0];j<=a[i][1];j++)
        {
            b[j]=0;
        }
    }
    for(i=0;i<=num;i++)
    {
        trees =  trees + b[i];
    }
    printf("%d",trees);
}
```

## AC 了但还不干净的地方

1. **`for(i=0;i<=20000;i++) b[i]=1;` 越界写一格。**
   `int b[20000]` 只有 20000 个格子，合法下标 **0 ~ 19999**；`i<=20000` 的最后一轮写的是 `b[20000]`，数组外面那一格。
   **AC 是运气**：这次加检测变量跑，前后两个 canary 都没被改（编译器在数组后面留了空隙）；换台机器、换个编译选项就未必。
   → 正确写法：`i < 20000`，或者干脆循环到 `i <= num`（反正只需要 0..l 这几格）。

2. **`int a[m][2];` 是变长数组。** 洛谷用 gcc 能过，**你在 VS2026 里会报 `C2057 应输入常量表达式`**。想在本机跑就得写 `int a[101][2];`（区域数 m ≤ 100）。

3. **`b[20000]` 开大了。** 路长 l ≤ 10000，10001 格就够；多开不算错，但会让人误以为树有两万棵。

4. **初始化放在 `scanf` 前面**，于是只能写死 20000。挪到 `scanf` 后面、用 `num` 当上限，就不需要记这个数了。

5. 小风格：`trees = trees + b[i];` → `trees += b[i];`；变量名 `num` 装的是路长，叫 `len` 更看得出来；结尾补 `return 0;`。

## 自测数据（我验过的）

| 输入 | 期望输出 | 说明 |
|---|---|---|
| `500 3` + 三行区域 | `298` | 官方样例（0 米那棵算进去） |
| `1 1` / `0 1` | `0` | 极端：全盖住 |
| `5 1` / `0 0` | `5` | 只盖 0 米那一棵 |

**树是 0 米到 l 米，一共 `l + 1` 棵**——0 也算一棵，这是这题最容易漏的地方。
