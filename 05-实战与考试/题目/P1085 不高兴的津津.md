# P1085 不高兴的津津

- 🔗 题目链接：https://www.luogu.com.cn/problem/P1085
- 练什么：**循环 + 找最大值**：7 天比大小，还要记住「第几天」
- 状态：☑ 2026-11-11 AC（有越界，已改到终版）
- ⬅ 回去：[[🎯 刷题总表]]


## 我的第一版（有真 bug）

```c
int num1[7], num2[7];
for (i = 1; i < 8; i++) scanf("%d %d", &num1[i], &num2[i]);
```

**越界写**：`int a[7]` 合法下标 0..6，我写到 `num1[7]` / `num2[7]`（第 8 格，不存在）。洛谷照样判过。

### 实测证据（canary）

在数组后面加 `int canary1 = 1111, canary2 = 2222;`，跑完 **`canary2` 变成 2** → 越界写真的砸到了旁边的变量。
`sizeof(num1) = 28`，`&num1[7] - &num1[0] = 28`（正好越出去一格）。

## 三处可瘦

1. 数组完全没必要（读完当场就用掉了，从不回查）。
2. `t > 8` 被 `t - 8 > max` 包住了，多余。
3. `num1[i] + num2[i]` 算了三次。

## 我的终版

```c
int max = 0, date = 0;
for (int i = 1; i <= 7; i++) {
    int s, e;
    scanf("%d %d", &s, &e);
    int t = s + e - 8;
    if (t > max) { max = t; date = i; }
}
printf("%d", date);
```

- `gcc -Wall -Wextra`：**0 警告**。
- 三组用例：七天全 `3 4` → `0`；第 3 天 `10 5` → `3`；第 2、5 天并列最高 → `2`（`>` 保证取最早）。
- 教学点：`max` 初值 0 同时兼了「默认答案」，所以最后的 `if (max == 0)` 可以彻底不要。

## 踩过的坑

- C22 越界（`int a[7]` 配 `i=1..7`）
- C9 `scanf` 漏 `&`（第二版漏了 `extra` 的，实测 segfault）
- **命令行 gcc 默认不做格式检查，必须 `-Wall`**；IDE（CLion/VS）默认开。
