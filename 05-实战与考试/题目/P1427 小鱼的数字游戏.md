# P1427 小鱼的数字游戏

## 📄 题目

**题目描述**：小鱼看到一串数字 $a_i$（长度不一定，**以 $0$ 结束**），要记住然后反着念出来（表示结束的那个 $0$ 不念）。

**输入格式**：一行内输入一串整数，以 $0$ 结束，以空格间隔。

**输出格式**：一行内倒着输出这一串整数，以空格间隔。

**数据范围**：$0 \leq a_i \leq 2^{31} - 1$，数字个数不超过 $100$，有且仅有末尾的一个数字是 $0$。

> 完整题面（含样例）：https://www.luogu.com.cn/problem/P1427

- 练什么：数组 + **读到 0 停** + **倒序输出**

## 版本账

| 版本 | 这版我改了什么 | 跑出来什么 | 真因（一句话） |
|---|---|---|---|
| v1 | `for(i=0; a=0; i++)` | `1416958013` | **`a=0` 是赋值不是比较**，条件恒为假 → 循环一次都没进，一个数都没读进来，打印的是 `num[0]` 里的垃圾值 |
| v2 | 改成 `a==0`、`a` 给初值 0、边界 `i>0` + `num[i-1]` | `0 1842243024` | **边界差一格**：读到 0 之后 `i` 停在它的下一格，`num[i-1]` 正好是那个 0，被念出来了 |
| v3 | 边界改 `i>1`，打印 `num[i-2]` | `1842243024` ✅ | 跳过收尾的 0，从序列最后一个真数开始 |

## AC 的代码（v3，原样）

```c
#include<stdio.h>
int main()
{
    int num[300];
    int a = 0;
    int i;
    for(i=0;a==0;i++)
    {
        scanf("%d",&num[i]);
        if(num[i]==0)
            a = 1;
    }
    for(;i>1;i--)
    {
        printf("%d ",num[i-2]);
    }
    return 0;
}
```

## 两次踩到的坑

### ① `=` 和 `==`（v1）

`a = 0` 这个式子自己的结果就是「装进去的那个 0」，而 0 表示不成立 → for 一次都没进去。
口诀：**条件里看见单独一个 `=`，就当它是假的。**

### ② 为什么 VS 没提醒（实测对比）

同一段 v1 代码，MSVC 编两次：

```text
/W3（VS 默认）  → 只有 warning C4996（scanf 不安全），没有别的
/W4            → v1_p1427.c(6): warning C4706: 赋值用作条件
```

**VS 默认 /W3 不报「赋值当条件」，要开到 /W4 才有 C4706。**
而 gcc 的 `-Wall` 自带这个检查（`-Wparentheses`），所以两边不一样，不是我看漏了。

### ③ 我的测试输入太弱（这次真正吃亏的地方）

我一直用 `1842243024 0` 试——序列里只有一个数，倒过来还是它，**倒序对不对根本看不出来**。
换成五个数 `7 8 9 10 11 0` 一眼就露馅。

**以后自己测至少三组：一个数 / 三个数 / 五个数（或更多）。** 只有两组数据是验不出顺序错误的。
