## 1. 定义：`\` 是"改意思"的开关

**逃逸字符 = 反斜杠 `\` + 后面跟一个字符，两个合起来算【一个】字符。**

单独的 `n` 是字母 n；`\n` 就不是 n 了 —— 变成「换行」。**反斜杠把后面那个字符的意思改掉了**，专门用来表示：

- **印不出来**的控制字符（换行、回车、退格、制表）
- 本身有特殊含义的字符（引号、反斜杠本身）

## 3. 实测程序 + 真实输出（gcc 16.2.0 真跑）

int main(void)
{
    /* 1. 逃逸字符的码值 */
    printf("\\b 回退一格   = %d\n", '\b');
    printf("\\t 到下一表格位 = %d\n", '\t');
    printf("\\n 换行       = %d\n", '\n');
    printf("\\r 回车       = %d\n", '\r');
    printf("\\\" 双引号     = %d\n", '\"');
    printf("\\' 单引号     = %d\n", '\'');
    printf("\\\\ 反斜杠本身 = %d\n", '\\');
    printf("(对照) 空格   = %d\n", ' ');

    /* 2. \t 的效果 */
    printf("A\tB\tC\n");
    printf("1\t22\t333\n");

    /* 3. \b 的效果 */
    printf("[abc\\bX] 打出来是: ");
    printf("abc\bX\n");

    /* 4. \r 的效果 */
    printf("[12345\\rXY] 打出来是: ");
    printf("12345\rXY\n");

           "如输入\"5 7\"表示5英尺7英寸：\n");
    return 0;
}

## 4. 三个"看得见效果"的（关键）

### ① `\b` 退格：`abc\bX` → 屏幕上 `abX`

退一格之后写的 `X`，把原来的 `c` **盖掉**了。

### ② `\r` 回车：`12345\rXY` → 屏幕上 `XY345`

光标**回到本行行首**，`XY` **覆盖**了前面的 `12`。

**这就是 `\r` 和 `\n` 的区别（必背）：**

| | 码 | 光标去哪 |
|---|---|---|
| `\n` 换行 | 10 | **下一行**的行首 |
| `\r` 回车 | 13 | **本行**的行首（不换行！） |

> 📌 Windows 里的"换行"其实是**两个字节 `\r\n`（13 10）** —— "回车换行"这个老词来自打字机：先把车头推回左边（回车），再转一圈上纸（换行）。

### ③ 覆盖 ≠ 清空（他的错题点）

`abc\rde` 为什么是 **`dec`**？因为 `\r` 只是把光标挪回去，**屏幕上原来那三个字母还在**，新的 `de` 一写上去，正好盖住 `a` `b`，剩下没被盖的 `c` 还在第三格。

**AI 用 Python 写了个小终端模拟器验证**（把字节流按真实终端渲染）：

```python
def render(s):
    """把一个字节流按真实终端的方式渲染出来（只模拟一行 + \r \b \n）"""
    line, cur = [], 0
    for ch in s:
        if ch == '\r':
            cur = 0                 # 回车：光标回到本行行首，不换行
        elif ch == '\n':
            print(''.join(line)); line, cur = [], 0
        elif ch == '\b':
            cur = max(0, cur - 1)   # 退格：光标左移一格
        else:
            if cur < len(line):
                line[cur] = ch      # 覆盖！不是往后插
            else:
                line.append(ch)
            cur += 1
    if line: print(''.join(line))

render("abc\rde\n")
render("12345\rXY\n")
render("abc\bX\n")
```

```
abc\rde   -> dec
12345\rXY -> XY345
abc\bX    -> abX
```

## 5. 课件第 1 张藏着的新东西：字符串挨着写会**自动拼成一句**

```c
printf("请分别输入身高的英尺和英寸，"
       "如输入\"5 7\"表示5英尺7英寸：");
```

这两行是**一个** `printf`，中间**什么都不用加** —— 两个字符串**挨着写，编译器自动接成一句**。

**为什么要拆成两行写**：字符串不能直接换行（L08 学过，会报 `missing terminating " character`）。长句子就拆成几段挨着写，靠"自动拼接"续上。

实测输出 `请分别输入身高的英尺和英寸，如输入"5 7"表示5英尺7英寸：` —— 中间没有空格、没有换行，确实接在一起。

> 📌 这里 `\"` 的作用：字符串里想打**双引号**，必须给它加 `\`，否则编译器以为字符串到头了。

## 6. 复习题（他的答案 + 讲评，2026-10-04）

> [!question]- Q1：`\n`（换行）和 `\r`（回车）有什么区别？
>
> **他答**：「换行是换到下一行，回车是回到这一行的开头」
> **判定**：✅ **满分** —— 一句话答到点上。
> **答**：`\n`（10）光标到**下一行行首**；`\r`（13）光标回**本行行首**、**不换行**。

> [!question]- Q2：打印出 `他说："你好"` 这一整行（要带引号），`printf` 怎么写？
>
> **他答**：「(他说：\"你好\");」
> **判定**：⚠️ **核心对了、句子没写全** —— `\"` 转义用对了（这才是考点），但没写 `printf(` 开头、结尾少的那个 `"` 也漏了，`\n` 也没加。
> **答**：
> ```c
> printf("他说：\"你好\"\n");
> ```
> 拆开看：外层 `"…"` 是字符串；中间两个引号用 `\"` 转义成**普通字符**；最后 `\n` 换行。

> [!question]- Q3：`printf("abc\rde");` 在真终端上会看到什么？
>
> **他答**：「rde」
> **判定**：❌ **错** —— 正解是 **`dec`**。
> **答**：`\r` 把光标送回行首，然后写 `d` **盖住 `a`**、写 `e` **盖住 `b`**，第三个位置上的 `c` **没被碰过，还在** → 屏幕上是 `dec`。
> **为什么错**：把 `\r` 想成"清空重写"了。**`\r` 只挪光标，不清屏** —— 盖多少算多少，没盖到的字还在。实测（Python 终端模拟）：`abc\rde` → `dec`。

## 7. 🔌 嵌入式视角

- **串口收到的"换行"通常是一对字节 `\r\n`**（很多模块的 AT 指令结尾就是 `\r\n`）→ 判断"一行收完"要认这两个；只认 `\n` 会漏，只认 `\r` 也会乱
- **`\r` 可以原地刷新一行**（回到行首重写）—— 做进度条、计数器刷新就用它，屏上不会一行一行往下滚
- **`\b` 用来做"假删除"**（终端里退格重写），命令行的行编辑就是这么实现的
- 打印多列数据（比如传感器三轴数值）用 `\t` 对齐，比手动数空格省事

---

## 8. 一句话总结

**逃逸字符就是「`\` + 一个字符」，两个算一个 —— `\` 把后面那个字符的意思改掉了。`\n` 去下一行、`\r` 回本行行首（覆盖不清屏）、`\b` 退一格、`\"` 打引号、`\\` 打反斜杠；另外两个字符串挨着写会自动接成一句（长句子换行写就靠它）。**
