# L03 字符与 ASCII 码

- 日期：2026-09-13
- 来源：我自己用 Visual Studio 学 C 的笔记（AI 整理 + 修正）
- 标签：`#C语言` `#基础语法` `#字符` `#ASCII`

> **一句话总结**：字符在内存里**本来就是数字**——`'A'` 就是 `65`，`'a'` 就是 `97`。所谓"ASCII 码"就是这张"字符 ↔ 数字"的对照表；C 里字符要用**单引号**括起来。

## 0. 原始笔记逐句核对（✅对 / ⚠️要改 / ❌错）

| 我原本写的 | 判定 | 修正后 |
|---|---|---|
| 在键盘上可以敲出的叫字符 | ⚠️ 不严谨（还跟我自己写的下一句打架） | 敲不出来的也是字符！换行符 `\n`、制表符 `\t`、响铃 `\a` 都是字符，但它们**不是"敲出来"的**（要敲 `\` 和 `n` 两个键来表示一个）。准确说：**单个符号**（字母、数字、标点、控制符）都叫字符 |
| C 语言中需要用 `''` 括起来 | ✅ 对 | 补两个重点：① 单引号里**只能放一个字符**，`'ab'` 是错的；② **单引号 = 字符，双引号 = 字符串**，`'a'` 和 `"a"` 是两个不同的东西 |
| 给字符一个二进制序列的过程叫做编码 | ✅ 对，说得好 | 正式名字叫**编码（encoding）**。字符 → 数字 → 二进制，这套映射表就是对照表 |

| 大小写字母十进制编码值差 32 | ✅ 对 | 实测 `'a' - 'A'` = **32**。所以小写转大写 = `-32`，大写转小写 = `+32` |
| 大写字母 ASCII 值从 65 到 90 | ✅ 对 | `'A'`=65 … `'Z'`=90 |
| 小写字母从 97 到 122 | ✅ 对 | `'a'`=97 … `'z'`=122 |
| 数字 0 到 9 的值从 48 到 57 | ✅ 对 | `'0'`=48 … `'9'`=57。⚠️ 别把**字符 `'0'`（48）**和**数字 `0`**搞混，见第 3 节 |
| `\n` 的值是 10 | ✅ 对 | **换行（LF）= 10**。另外几个常一起记：`\t`=9、`\r`=13（回车）、`\0`=0 |
| ASCII 码值 0 到 31 是不可打印的字符 | ⚠️ 名字要精确 | 这 32 个准确叫**控制字符**（管动作的，不是给人看的）。⚠️ 还有 **127（DEL）** 也不能打印；另外 **32 是空格**，**是能打印的**（所以别记成"0 到 32 都不能打印"） |

## 1. 字符要用单引号，而且只能装一个

```c
'a'      // ✅ 字符常量，我写了 'a'
'ab'     // ❌ 单引号里塞了两个字符
"a"      // ❌ 这是【字符串】，不是字符
```

**实测**：`'ab'` 编译器会警告 `multi-character character constant`（多字符字符常量），我这边算出来是乱七八糟的 24930——**语法上不拦你，但结果是不可靠的**，绝对不能这么写。

**实测**：`char c = "a";` 直接报错：

```
error: initialization of 'char' from 'char *' makes integer from pointer without a cast
```

翻译成人话：**"你拿一根『字符串的管子』往一个『单个字符的小格子』里塞，塞不下。"** 单引号是格子里放一颗豆子，双引号是一串豆子。

| 写法 | 是什么 | 里面能有几个 |
|---|---|---|
| `'a'` | 字符常量 | **必须且只能 1 个** |
| `"a"` | 字符串 | 任意多个（含 0 个：`""`） |

## 2. 字符 ↔ 数字：这是本课最重要的一层

**字符在内存里根本没有"字符"，只有数字。** 你看到的 `A`，是 `printf` 拿到数字 65 后**换成图形给你看**的。

我实跑了一遍（把同一个字符用两种方式打印）：

| 字符 | 用 `%c` 打（当字符看） | 用 `%d` 打（当数字看） |
|---|---|---|
| `'A'` | A | **65** |
| `'a'` | a | **97** |
| `'0'` | 0 | **48** |
| `'\n'` | （换个行） | **10** |

> 比方：字符就像**穿衣服的人**，数字是**这个人的工号**。`%c` 是"看脸"，`%d` 是"查工号"——同一个人，两种看法。

### 这就是为什么能做"大小写转换"

```c
'a' - 32   →  'A'      // 小写转大写
'A' + 32   →  'a'      // 大写转小写
```

**实测结果**：`小写转大写: A`、`大转小: a`、`'a'-'A' = 32`。全对。

## 3. ⚠️ 最容易混的一对：字符 `'0'` 和数字 `0`

| 写法 | 是什么 | 值 |
|---|---|---|
| `'0'` | **字符**（带单引号） | **48** |
| `0` | **数字**（不带引号） | 0 |

```c
printf("%d\n", '0');   // 打出来是 48  ← 字符 '0' 的编号
printf("%d\n", 0);     // 打出来是 0   ← 数字 0 本身
```

**要算数就用不带引号的（`0`），要显示成字符就用带引号的（`'0'`）。** 以后输入输出时会天天遇到这个坑（比如把输入的 `'5'` 变成数字 5 用来算加法，得 `'5' - '0'`）。

## 4. 这张表要背哪几个（够用了）

| 范围 | 十进制 | 记忆法 |
|---|---|---|
| `'A'` ~ `'Z'` | 65 ~ 90 | 大写从 65 起 |
| `'a'` ~ `'z'` | 97 ~ 122 | 小写从 97 起（比大写大 32） |
| `'0'` ~ `'9'` | 48 ~ 57 | 数字字符从 48 起（**不是从 0 起！**） |
| 空格 | 32 | 空格是能打印的 |
| `\0` | 0 | 字符串的结束标志（后面学字符串时会考） |
| `\t` | 9 | Tab |
| `\n` | 10 | 换行（LF） |
| `\r` | 13 | 回车（CR） |
| 0 ~ 31 | — | **控制字符**，不可打印（管动作的） |
| 127 | — | DEL（删除），**也不可打印** |

- ASCII 一共 **0 ~ 127，128 个字符**（7 个二进制位就够表示）。128~255 的叫"扩展 ASCII"。
- **不可打印的字符是"下命令"的**：`\n` 让光标换行、`\t` 让光标跳格、`\0` 说"字符串到这儿结束"。它们没有字形，打不出来。

## 5. 完整例子（手打，不许复制）

```c
#include <stdio.h>

int main()
{
    printf("'A' 当字符打: %c   当数字打: %d\n", 'A', 'A');
    printf("'a' 当字符打: %c   当数字打: %d\n", 'a', 'a');
    printf("'0' 当字符打: %c   当数字打: %d\n", '0', '0');
    printf("小写转大写: %c\n", 'a' - 32);
    return 0;
}
```

**实跑结果**：

```
'A' 当字符打: A   当数字打: 65
'a' 当字符打: a   当数字打: 97
'0' 当字符打: 0   当数字打: 48
小写转大写: A
```

## 7. 复习题（先自己答）

1. 下面哪个写法是**错的**？为什么？
   ```c
   'A'      "A"      'AB'      ' '
   ```
2. `'H'` 的 ASCII 值是多少？`'h'` 又是多少？两者差多少？
3. `printf("%d\n", '0');` 会打印出什么？为什么不是 0？
4. 字符 `'A'` 和数字 `65` 在内存里存的东西有什么区别？

> [!question]- 参考答案（先自己答完再点开）
>
> 1. `'AB'` 错——**单引号里只能放一个字符**。`'A'` 字符 ✔、`"A"` 是字符串 ✔（合法，但不是字符）、`' '` 是空格字符 ✔（合法，空格也是一个字符）。
> 2. `'H'` = 72，`'h'` = 104（97 + 7），差 **32**。
> 3. 打印 **48**。因为 `'0'` 是**字符**，它的 ASCII 码是 48；`%d` 是"当数字打"，所以就打出了它的编号。
> 4. **没区别**——存进去的二进制一模一样。区别只在**编译器怎么解释它**（`%c` 当字符显示，`%d` 当数字显示），以及**类型名不同**（`char` vs `int`）。

**我的答案**：1. 3 和 4 错（4 是"中间没有字符"）　2. 72、104，差 32　3. 打印的是 `'0'` 的字符编号，因为外面带了 `''`　4. 不知道，应该没区别

**评分：3 / 4**（比前两轮明显进步，第 2、3、4 题全对 🎉）

| 题 | 判定 | 讲评 |
|---|---|---|
| 1 哪个写法错 | ❌ 半对 | `'AB'` 判对了，理由也对（**单引号里只能放一个字符**）👍 但**把 `' '` 也判成错的**——这里是本课最容易中的陷阱，见下面 |
| 2 `'H'`/`'h'` | ✅ 完全正确 | 72、104，差 32。答得干脆，说明表记住了 |
| 3 `printf("%d\n", '0')` | ✅ 完全正确 | "打印 `'0'` 的字符编号，因为带了单引号"——**这句话就是标准答案**，说明第 2 节你真吃透了 |
| 4 `'A'` 和 `65` 的区别 | ✅ 对（但自己没底气） | "没区别"**就是正确答案**。下次答这种题要有底气，理由：存的二进制一模一样，区别只在**编译器怎么解释**（`%c` 看脸 / `%d` 查工号）和**类型名不同**（`char` / `int`） |

### 重点纠正：`' '` 不是"没有字符"，它是**空格字符**

我原来以为 `' '` 中间是空的 → 错。**那里面有一个空格！** 空格也是一个正经字符，编号 32。

实测对比（真的编了两遍）：

| 我写的 | 结果 | 编译器说 |
|---|---|---|
| `printf("%c", ' ')` | 打印 `[ ]`（中括号中间有个空隙） | ✅ 正常，编号 **32** |
| `printf("%d", ' ')` | 打印 **32** | ✅ 正常 |
| `printf("%d", '')` | ❌ | `error: empty character constant`（空的字符常量） |

**结论**：
- `' '` = **中间有一个空格** = 合法字符，值 32（空格在键盘上那么大一个键，怎么会"没有字符"）
- `''` = **真的一无所有** = 非法，报 `empty character constant`
- 所以第 1 题的正确答案：**只有 `'AB'` 是错的**；`'A'` ✔、`' '` ✔（空格）、`"A"` ✔（合法，但它是**字符串**不是字符）

> 记忆法：**单引号是个小盒子，里面必须放着一样东西。**
> 放一颗豆子 = `'a'`；放一个空格 = `' '`（也算放了一样东西）；空的盒子 = `''` → 报错；两颗豆子 = `'ab'` → 报错。
