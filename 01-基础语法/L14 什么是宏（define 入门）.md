# L14 宏是什么（`#define` 入门）

- 日期：2026-09-17
- 来源：我问的问题——修 `scanf` 报错那行 `#define _CRT_SECURE_NO_WARNINGS 1` 里的"宏"到底是啥
- 标签：`#C语言` `#预处理` `#define` `#宏`

> **一句话总结**：**宏 = 编译开始之前，由"预处理器"做的文本替换或开关标记。** `#define MAX 100` 就是把代码里所有的 `MAX` **原样替换成 `100`**（不是变量、不占内存、没有类型）。最常见的三种用法：**定义常量、定义"小函数"、当条件编译的开关**——修 `scanf` 报错用的就是第三种（开关）。

> 现在只需要记住**一句操作**：修 `scanf` 报错，就在文件第一行写 `#define _CRT_SECURE_NO_WARNINGS 1`——**照做就行，不用懂为什么**。

## 1. 宏的"位置"：它比编译更早发生

还记得 L02 学过的**四步流水线**吗？宏就活在**第 1 步**：

| 步骤 | 谁在干 | 干的事 |
|---|---|---|
| **1 预处理** | **预处理器** | **抄头文件、删注释、处理 `#define`（宏）和 `#ifdef`** ← 宏在这里 |
| 2 编译 | 编译器 | 翻译成机器码 |
| 3 汇编 | 汇编器 | 生成目标文件 |
| 4 链接 | 链接器 | 拼成 exe |

**关键点：宏的活儿在编译器上班之前就干完了。** 所以宏有个外号叫**"编译前的文本替换工"**。

## 2. 用法一：对象式宏（给一个值起名字）—— 最常见的

```c
#define MAX 100

int main()
{
    int a = MAX;        // 编译前被替换成 int a = 100;
    int b = MAX + 1;    // 编译前被替换成 int b = 100 + 1;
    return 0;
}
```

**实测：让编译器"只做预处理、先别编译"，看它替换成什么样**（`gcc -E`）：

```c
int main()
{
    int a = 100;        // ← MAX 已经不见了，变成了 100
    int b = 100 + 1;    // ← 一样
    return 0;
}
```

✅ **眼见为实：宏就是"文本替换"，不是变量。**

> ⚠️ **注意**：`#define` 那行**没有分号、也没有等号**！
> `#define MAX 100` ✅ ｜ `#define MAX 100;` ❌（分号会被一起替换进去，代码就崩了）

## 3. 用法二：函数式宏（像个"小函数"，但有陷阱）

```c
#define SQUARE_BAD(x)  x * x           // ❌ 没加括号
#define SQUARE_OK(x)   ((x) * (x))     // ✅ 每个参数和整体都加括号
```

**实测两种的结果（差得离谱！）**：

```
SQUARE_BAD(1+2) = 5    ← 我以为是 9
SQUARE_OK (1+2) = 9    ← 加括号才对
```

**为什么错的会变成 5？** 因为宏是**纯文本替换**：

```c
SQUARE_BAD(1+2)  →  1+2 * 1+2  →  1 + (2*1) + 2  →  5
```

> ⚠️ **教训**：写函数式宏，**参数和整体都要套括号**。
> （而且这还说明：宏**没有类型检查**，编译器是在替换完才发现问题的——所以现在的主流建议是**能用普通函数就用函数**，宏只用在"必须用宏"的地方。）

## 4. 用法三：当"开关"用（`#define` + `#ifdef`）—— 修 scanf 报错就是这种

```c
#include <stdio.h>

int main()
{
#ifdef DEBUG_ON
    printf("【调试版】打开了开关\n");
#else
    printf("【正式版】开关没开\n");
#endif
    return 0;
}
```

**实测两种编译结果**：

| 编译方式 | 输出 |
|---|---|
| 什么也不加 | `【正式版】开关没开` |
| 加 `-DDEBUG_ON`（等于在文件里写 `#define DEBUG_ON`） | `【调试版】打开了开关` |

**原理**：`#ifdef XXX` 的意思是**"如果 `XXX` 这个宏被定义过，就编译这一段"**。

### 🔑 这下就懂了：`_CRT_SECURE_NO_WARNINGS` 是什么

```c
#define _CRT_SECURE_NO_WARNINGS 1     // ← 打一个"标记"
#include <stdio.h>                     // ← 头文件里有一句 #ifdef 检查这个标记
```

`stdio.h` 里大概是这么写的（简化）：

```c
#ifdef _CRT_SECURE_NO_WARNINGS
    /* 用 scanf 的人自己不介意 -> 不报警告 */
#else
    /* 没定义这个宏 -> 把 scanf 标记成"不安全" -> 报 C4996 */
#endif
```

**所以那个宏的作用不是"运行什么代码"，而是"举一面旗子给头文件看"**——头文件看到旗子就不拦你。

### ⚠️ 为什么它必须写在《所有 `#include` 之前》

**因为 `#include` 是把头文件的内容"抄进来"**：

- 抄 `stdio.h` 的时候，里面那句 `#ifdef` **当场就要检查**；
- **宏必须在"检查发生的那一刻"之前就定义好**；
- 写在 `#include` 后面 → 检查时还没有旗子 → 照样报错。

> 📌 **通用规律（以后天天用）**：`#define` 定义的东西，**必须先定义、后使用**——宏是"从上往下走着替换"的。

## 5. 宏 vs 变量/常量（别搞混）

| | 宏 `#define MAX 100` | 变量 `int max = 100;` |
|---|---|---|
| 啥时候处理 | **编译之前**（预处理阶段） | 程序**运行时** |
| 占内存吗 | **不占**（只是个名字，替换完就没了） | 占（要一块内存存值） |
| 有类型吗 | **没有**（就是一堆字符） | 有（`int`） |
| 能改吗 | 不能（编译时定死） | 能（`max = 200;`） |
| 有分号吗 | **没有** | 有 |
| 名字习惯 | **一般全大写**（`MAX`、`PI`） | 小写（`max`、`pi`） |

> 所以宏**不是变量**、"常量"也只是个说法——它本质是**给编译器看的替换规则**。

- [ ] 为什么叫"宏"这个名字？（来自英文 **macro**，意思是"宏观/一大块"，指"把一段东西打包成一个名字，用的时候展开"）
- [ ] 什么时候正式学预处理？（**阶段12 进阶选学**里的"预处理"章节，你会学到 `#define`、`#ifdef`、`#include` 背后的机制——现在只是提前用了一下）

## 7. 复习题（先自己答）

1. 宏是在**哪一步**被处理的？（预处理 / 编译 / 链接？）
2. `#define MAX 100` 之后，代码里写 `int a = MAX;`，编译前它会变成什么？
3. `#define SQUARE(x) x*x`，那 `SQUARE(1+2)` 算出来是几？为什么不是 9？
4. `#define _CRT_SECURE_NO_WARNINGS 1` 这行的作用是"运行一段代码"吗？那是什么？
5. 为什么这行必须写在 `#include <stdio.h>` 的**前面**？

> [!question]- 参考答案（先自己答完再点开）
>
> 1. **预处理**阶段（编译之前），由**预处理器**处理。编译器上场时，宏已经被替换完了。
> 2. 变成 **`int a = 100;`**（实测 `gcc -E` 的输出就是这样）。
> 3. **5**。因为宏是纯文本替换：`SQUARE(1+2)` → `1+2*1+2` → 先乘后加 → `1+2*1+2 = 5`。要写对必须加括号：`#define SQUARE(x) ((x)*(x))`。
> 4. **不是运行代码**，它是**打一个"标记"（旗子）**给头文件看。`stdio.h` 里有 `#ifdef` 检查这个标记，**看到标记就不把 `scanf` 标记成"不安全"**，于是不报 C4996。
> 5. 因为 `#include` 是**把头文件内容抄进来**，抄进来的时候里面那句 `#ifdef` **当场就检查**。宏必须先定义好，检查时才看得到；写在后面 = 检查时还没有旗子 → 照样报错。

## 8. 嵌入式视角（宏在嵌入式里是"重灾区"也是"利器"）

- **寄存器地址、引脚定义全靠宏**，比如 `#define LED1_PIN 5`、`#define GPIOA_BASE 0x40010800`——**改一个宏，全项目生效**，这是嵌入式代码能维护的原因之一。
- **调试代码用宏开关**：`#ifdef DEBUG` 包住串口打印，正式版**一个字节都不占**（因为预处理阶段就删掉了）——这就是"宏不占空间"的实际价值。
- **条件编译做移植**：`#ifdef STM32F1` / `#elif defined(STM32F4)`，同一份代码适配不同芯片。
- ⚠️ **反面**：宏满天飞的代码很难调试（**编译报错的行号常常对不上**，因为替换后行数/内容都变了）。所以嵌入式老规矩是：**宏只用来做"配置"和"开关"，逻辑一律用函数。**
