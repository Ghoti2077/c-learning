# L01 main 函数与程序框架（第一个 C 程序）

- 日期：2026-09-13
- 来源：我自己用 Visual Studio 学 C 的笔记（AI 整理 + 修正）
- 标签：`#C语言` `#基础语法` `#VisualStudio`

> **一句话总结**：C 程序从 `main` 开始跑、到 `return 0;` 结束；语句写在函数体 `{}` 里、用 `;` 收尾，语法符号必须是**英文**。

---

## 0. 原始笔记逐句核对（✅对 / ⚠️要改 / ❌错）

| 我原本写的 | 判定 | 修正后 |
|---|---|---|
| main 函数是程序的入口，每个工程（目前指源文件）有且仅有一个 | ⚠️ 半对 | 入口✅。但不是"每个源文件一个"——是**整个工程加起来只能有一个 `main`**；两个源文件各写一个 main，链接就报错 |
| f11 可以逐行运行程序 | ⚠️ 不准确 | F11 是**调试**里的"逐语句"（会钻进函数内部），不是"运行程序"。光想跑 → `Ctrl+F5`；一行一行看 → F10 更常用 |
| int 表示整数 | ✅ 对 | 补一句：`int` 是整型，只能装整数，装不了小数（小数用 `float`/`double`） |
| `int main() { return0; }` | ❌ 错 | `return 0;`——`return` 和 `0` 之间**有空格**，末尾**有英文分号** |
| 程序不能使用中文符号 | ⚠️ 要补边界 | 语法符号（`;` `(` `)` `"` `,`）必须英文半角✅；但**字符串内容里的中文是允许的**，`printf("你好");` 完全没问题 |
| 一条语句后面要加 `;` | ⚠️ 要补例外 | 对，但**不是每行都加**：`#include <stdio.h>`、`int main()`、`{`、`}` 后面**都不加**分号 |
| 程序必须写在 `{}` 之间 | ⚠️ 半对 | 是**可执行的语句**要写在函数的 `{}` 里；`#include` 写在 `{}` 外面（它连函数都不是） |
| return 0 默认表示正常返回 | ✅ 对 | 0 = 约好的"正常"，非 0 = 出错了。写法是 `return 0;` |
| int 叫返回类型，main 是返回类型 | ❌ 错 | `int` 是返回值类型，**`main` 是函数名**（见第 3 节） |

## 1. main 是程序的入口

- `main` 是程序的**入口**，也就是电脑运行这个程序时**第一件要做的事**。
- 一个工程（可以理解成一个能独立运行的程序）里，`main` **有且仅有一个**：不能没有，也不能有两个，否则系统不知道该从哪儿开始。

> 比方：`main` 就像家里的大门。回家只能从大门进，家里也不能有两扇大门——两扇门系统就蒙了。

## 2. main 函数框架（背下来）

```c
int main()
{
    return 0;
}
```

> 这个骨架要能闭着眼敲出来。以后所有代码都往 `{ }` 里面塞。

## 3. `int` 和 `main` 分别是什么（这里修正一下原来的说法）

我原来写的：「`int` 叫返回类型，`main` 是返回类型」——**前半句对，后半句要改**：

| 部分 | 叫什么 | 干啥的 |
|---|---|---|
| `int` | **返回值类型** | 这个函数干完活，交给系统的结果是什么类型的。`int` 就是整数 |
| `main` | **函数名** | 这个函数的名字就叫 main。系统靠这个名字找到入口 |
| `( )` | 参数列表 | 空着表示这个函数不需要别人给它喂东西 |
| `{ }` | 函数体 | 要执行的代码全写在这里面 |

完整念一遍：**`int`（返回整数）`main`（名字叫 main）`( )`（不要参数）`{ }`（干的活在这里）**

> 比方：`int` 是"我退给你的东西是一张整数券"，`main` 是"我的名字"，`{ }` 是"我的工作间"。名字和退什么东西，是两回事。

## 4. `return 0;` 是啥意思

- `return` = 函数干完了，往回交东西。
- `return 0;` 里的 **0 是约定俗成的"一切正常"**——程序正常跑完，就交个 0 给系统。
- 交别的数字（比如 1）一般表示"出错了"。这是**约定**，不是 C 语言发明的规矩。
- 注意写法：`return 0;`，`return` 和 `0` 中间**要有空格**，结尾**要有英文分号**。写成 `return0;` 编译不过。

> 嵌入式提醒：单片机的 `main` 也是入口，但里面通常写 `while(1)` 死循环，**永远不 return**——因为单片机的程序不允许"结束"，结束了机器就没人管了。

## 5. 四条铁律（错一个就编译不过）

| 铁律 | ❌ 错的 | ✅ 对的 |
|---|---|---|
| 只能用**英文**符号 | `printf（"hi"）；` 全角括号、全角分号 | `printf("hi");` |
| 一条语句结尾要加 `;` | `return 0` | `return 0;` |
| 代码必须写在 `{}` 之间 | 语句写在 `{` 外面 | 都在 `{ }` 里 |
| 花括号成对出现 | 只写 `{` 不写 `}` | `{` 和 `}` 配一对 |

> 中文符号是新手第一大坑，因为**看不出区别**：
> `；`（中文分号）≠ `;`（英文分号）　`（）`（中文括号）≠ `()`（英文括号）
> 输入法切到英文再敲符号，或者把输入法的"中文标点"关掉。

## 6. 我的第一个完整程序（手打，不许复制）

```c
#include <stdio.h>

int main()
{
    printf("hello C\n");
    return 0;
}
```

**运行结果**（我用 gcc 实跑了一遍，你在 VS 里跑出来应该一样）：

```
hello C
```

> `#include <stdio.h>` 是"借用别人的工具箱"（printf 就住在里面），`printf` 是往屏幕上打字，`\n` 是换行。这两个下一课细说。

## 8. 复习题（自己先答，再往下看答案）

1. 一个工程里能有几个 `main`？如果一个都没有会怎样？
2. `int main()` 这句话里，哪一部分是函数名，哪一部分是返回值类型？
3. 下面三行哪一行编译不过，为什么？
   ```c
   return 0;
   return0;
   return 0；
   ```

> [!question]- 参考答案（先自己答完再点开）
>
> 1. 只能有 1 个。一个都没有 → 链接时报错，系统找不到入口（VS 里会看到 `LNK2019` / `无法解析的外部符号 _main`）。
> 2. `int` 是返回值类型，`main` 是函数名。
> 3. 第 2 行少了空格和分号（`return0`）；第 3 行结尾是**中文分号** `；`。只有第 1 行对。

## 9. 复习题讲评（2026-09-13 我的作答）

**我的答案**：1. 只能有一个，不知道　2. main 是函数名，int 是返回值表示返回整数　3. 一和二都不行

**评分：2 对、1 错、1 空**

| 题 | 判定 | 讲评 |
|---|---|---|
| 1 能有几个 main | ✅ 对（后半空着） | 后半"没有 main 会怎样"下面补了 |
| 2 谁是函数名/返回类型 | ✅ 完全正确 | `main` = 函数名，`int` = 返回值类型（返回整数）。这题说明第 3 节改对了 |
| 3 哪行编译不过 | ❌ 错 | 只有 **2、3 行**不过，**第 1 行 `return 0;` 是完全正确的**——我把对的那行也判死了 |

### 编译器实测（我让编译器自己报的错，不是我瞎猜）

| 写法 | 结果 | 编译器原话 |
|---|---|---|
| `return 0;` | ✅ 编译通过，正常打印 | 无报错 |
| `return0;` | ❌ 编译错 | `error: 'return0' undeclared`（"return0 没声明过"——它被当成一个名字了，不是关键字） |
| `return 0；`（中文分号） | ❌ 编译错 | `error: invalid suffix '；' on integer constant` + `expected ';' before '}' token`（就在喊"我这儿缺个分号"） |
| 整个工程没有 main | ❌ **链接**错 | gcc 说 `undefined reference to 'WinMain'`；VS 说的是 `LNK2019 无法解析的外部符号 _main` —— 说法不同，**原因一样：系统找不到入口** |

> **关键区别（现在就记住）**：
> - 少了分号、中文符号、`return0` → **编译**就挂了（compiler 说：你写的句子我看不懂）
> - 没有 `main` → 前一步能过，**链接**时才挂（linker 说：句子我都看懂了，可是你让我从哪儿开始跑？）
>
> 比方：编译 = 检查每个字写对没有（`return0` 像把"回家"写成了"回加"，老师一眼看出错字）；链接 = 把所有人的台词拼起来演戏，这时候才发现"主角压根没来"。

### 第 1 题后半：没有 main 会怎样

- 程序能通过编译（每行语法都对），但**链接不过**，生成不了 exe，VS 报 `LNK2019 / LNK1120`。
- 原因：可执行程序必须有个起点，链接器就是去找 `main` 这个名字，找不到就罢工。
- 比方：一栋楼装修得再漂亮，**没有大门**就没人进得去。
