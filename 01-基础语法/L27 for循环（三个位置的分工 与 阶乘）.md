# L27 `for` 循环（"计数循环"）

- 日期：2026-09-21
- 来源：翁恺《C语言程序设计》for 循环（课件 4 张 + 视频截图）
- 我的理解（原话）：「for 循环圆括号中间第一个是初始条件，第二个是循环继续条件，第三个是循环内容」
- 标签：`#C语言` `#基础语法` `#循环` `#for`

> **一句话总结**：
> **`for (① 初始化; ② 循环条件; ③ 每轮做完后的动作)`** —— 三个零件**挤在一行里**，所以它最适合"数着次数做"的循环。
> ⚠️ **第三个位置不是循环内容！** 循环内容（循环体）在**花括号 `{}` 里**；第三个位置管的是"**这一轮做完后计数器怎么变**"（`i++`、`count--`）。

---

## 1. 课件：for 是"计数循环"

![[L27-课件 for循环像计数循环.png]]

![[L27-课件 for等于对于（读法）.png]]

**翁恺的读法（很值得背下来）**：

```c
for (count = 10; count > 0; count--)
```

> **读成**："对于一开始的 `count = 10`，当 `count > 0` 时，重复做循环体；
> 每一轮循环在**做完循环体之后**，使得 `count--`。"

## 2. 我的理解核对（关键是第三个位置）

| 我说的 | 判定 | 精确说法 |
|---|---|---|
| 第一个是初始条件 | ✅ 对 | **初始化**：进循环**之前只做一次** |
| 第二个是循环继续条件 | ✅ 对 | **每轮开始前检查一次**；成立就做循环体，不成立就退出 |
| 第三个是循环内容 | ❌ **错** | 第三个是**步进（每轮做完后的动作）**，比如 `i++`、`count--`。**循环内容是花括号 `{}` 里的那些语句** —— 两者不是一个东西 |

**对比着看更清楚**：

```c
for (i = 1; i <= n; i++) {     /* ← 这三个是"循环的管理零件" */
    fact *= i;                  /* ← 这个才是循环内容（每轮真正干的事） */
}
```

**打比方**：`for` 像**跑步机的控制面板**——
① 设好起始速度（初始化，只设一次）、② 设好"跑到什么条件就停"（条件，一直盯着）、
③ 每跑一圈自动调一次档（步进）；**在跑道上真正跑的动作（循环体）是你自己做的**。

### 三个零件的执行时机（实测探针）

```c
for (int i = 1; i <= 3; i++) {
    printf("  循环体：i = %d\n", i);
}
```

实测输出：

```
[进入 for 之前]
  循环体：i = 1
  循环体：i = 2
  循环体：i = 3
[离开 for 之后]
```

**完整时序**（`for (①; ②; ③)`，共 3 轮）：

| 时刻 | 发生什么 |
|---|---|
| 进 for 之前 | 执行 **①**（初始化）——**只这一次** |
| 第 1 轮 | 检查 **②**（真）→ 做循环体 → 执行 **③** |
| 第 2 轮 | 检查 **②**（真）→ 做循环体 → 执行 **③** |
| 第 3 轮 | 检查 **②**（真）→ 做循环体 → 执行 **③** |
| 结束 | 再检查 **②**（**假**）→ 退出 |

**口诀**：**②③ 一轮一对，循环体夹在中间**；**① 只在最开始出现一次**。

**实测确认**（把步进换成会计数的写法，数它执行几次）：

```
 循环体：i = 1（此时步进已执行 0 次）
 循环体：i = 2（此时步进已执行 1 次）
 循环体：i = 3（此时步进已执行 2 次）
退出后：i = 4，步进一共执行 3 次
```

→ **循环体做 N 次，步进也执行 N 次**；**循环退出后 `i` 比"最后一次进循环时的值"大 1**（退出前那次 ③ 已经跑过了）。这在以后拿 `i` 的值做判断时要注意。

## 3. 同一件事：while 版 vs for 版

![[L27-对照 阶乘的while版代码.png]]

![[L27-课件 阶乘的for版代码.png]]

`for` 就是把 `while` 里**散在三处**的零件**收进一行**：

| | 初始化在哪 | 条件在哪 | 步进在哪 |
|---|---|---|---|
| `while` 版 | 循环**前**另写一行（`int i = 1;`） | `while (i <= n)` | 循环体**里**最后一行（`i++;`） |
| `for` 版 | **圆括号第一个位置** | **第二个位置** | **第三个位置** |

**两者完全等价**，`for` 只是把"管理零件"集中在头部，读起来更清爽、也更**不容易忘写 `i++`**（忘了就是死循环）。

## 4. 翁恺的"小套路"：求和从 0 开始，求积从 1 开始

![[L27-课件 小套路（求和0求积1）.png]]

| 目的 | 结果变量初值 | 为什么 |
|---|---|---|
| **求和**（`sum += i`） | **0** | 0 加任何数都不变，第一轮加上去就是第一个数 |
| **求积**（`prod *= i`） | **1** | 1 乘任何数都不变，不污染结果 |

**反着写实测的后果**：

```
1~5 求和（初值 0 += ）= 15     ✅
1~5 求积（初值 1 *= ）= 120    ✅
1~5 求积（初值 0 *= ）= 0      ❌ 永远是 0（0 乘任何数都是 0）
```

**一句话**：**加法的"什么都没加"是 0；乘法的"什么都没乘"是 1。**

## 5. 我的阶乘程序核对

![[L27-我的阶乘程序（for版）.png]]

```c
int main() {
    int n;
    scanf("%d", &n);
    int fact = 1;                     /* ✅ 求积初值 1，小套路用对了 */
    int i = 1;
    for(i=1;i<=n;i++) {               /* ✅ 三个零件位置全对 */
        fact *= i;                    /* ✅ 循环体只有一件事，干净 */
    }
    printf("%d!=%d\n", n, fact);       /* ✅ 这次带 \n 了！ */
    return 0;
}
```

### ✅ 写对的地方

- 三个零件位置**完全正确**（`i=1` / `i<=n` / `i++`）
- `fact = 1` 初值对（小套路应用到自己的程序里了）
- **`\n` 有了** ✅（前几轮的红警见效）
- 结构干净：初始化→循环→输出，没有多余的调试语句

### ⚠️ 两处要注意

**① 数字一大就溢出**（实测，`fact` 是 `int`，最大只能装 2147483647）

| 输入 | 输出 | 判定 |
|---|---|---|
| 0 | `0!=1` | ✅ 正确（0 的阶乘定义为 1，而且 for 一次都不进，`fact` 保持 1，**刚好对**） |
| 1 | `1!=1` | ✅ |
| 5 | `5!=120` | ✅ |
| **12** | `12!=479001600` | ✅ **int 能装下的最后一个** |
| **13** | `13!=1932053504` | ❌ 真值是 6227020800 → **溢出** |
| 17 | `17!=-288522240` | ❌ 溢出，还变成负数了 |
| 20 | `20!=-2102132736` | ❌ 溢出 |
| -3 | `-3!=1` | ⚠️ 说明负数进不了循环（题目不会这么出） |

→ **溢出原理以后学**（已记待学），现在只要记住：**阶乘到 13 就不对了**，想算更大的得换类型（`long long` 也不行到 21，之后要上"大数"处理）。

**② 小冗余**：`int i = 1;` 后面 `for(i=1;...)` 又赋了一次 1，等于写了两遍。可以二选一：

```c
int i;                        /* 只声明，不赋值 */
for (i = 1; i <= n; i++) { ... }

/* 或者更现代的写法（C99 起支持，作用域只在循环里）： */
for (int i = 1; i <= n; i++) { ... }
```

（翁恺课件里也是 `int i = 1;` 再 `for(i=1;...)`，所以**不算错**，只是可以写得更干净。）

## 6. 复习题（先自己答）

1. `for (①; ②; ③)` 里，**哪一部分是"每轮做完之后"才执行的**？循环体在哪？
2. `for (int i = 1; i <= 3; i++)` 的 ③ 一共执行了几次？（提示：最后一轮做完还会执行一次）
3. 求和变量的初值该给几？求积变量的初值该给几？为什么？
4. 把 `for (i = 1; i <= n; i++) { fact *= i; }` 改写成 `while` 版，怎么写？
5. 为什么 `n = 13` 时我的阶乘程序就不对了？

> [!question]- 参考答案（先自己答完再点开）
>
> 1. **③（第三个位置）**在每轮循环体做完之后执行；**循环体是花括号 `{}` 里的语句**（第三个位置不是循环内容）。
> 2. **3 次**（不是 4 次），`i` 最后变成 4。每轮循环体做完执行一次 ③，3 轮就是 3 次 —— 第 3 次 ③ 把 `i` 变成 4，然后才检查 ②（`4<=3` 假）退出。**实测**（把"步进"换成会计数的表达式）：
>    ```
>     循环体：i = 1（此时步进已执行 0 次）
>     循环体：i = 2（此时步进已执行 1 次）
>     循环体：i = 3（此时步进已执行 2 次）
>    退出后：i = 4，步进一共执行 3 次
>    ```
>    **规律**：**循环体做 N 次，步进也执行 N 次**（步进紧跟在每轮循环体后面）；**循环结束后 `i` 比最后进入循环时的值大 1**（因为退出前那一次 ③ 已经执行过了）。
> 3. 求和给 **0**（0 加任何数不变）；求积给 **1**（1 乘任何数不变）。求积给 0 的话结果永远是 0（实测 `1~5 求积（初值 0）= 0`）。
> 4. ```c
>    int i = 1;
>    while (i <= n) {
>        fact *= i;
>        i++;              /* ← 步进搬到循环体最后一行 */
>    }
>    ```
>    （初始化搬到 while 前，条件放 while 括号里，步进塞进循环体末尾）
> 5. 因为 `int` 最大装 2147483647，而 `13! = 6227020800` **装不下** → **溢出**（实测输出 `1932053504`，17! 甚至输出负数）。12! = 479001600 是 int 的最后一个能装下的阶乘。

## 7. 嵌入式视角

- **`for` 在嵌入式里专门管"固定次数"的活**：扫 8 个数码管、读 10 路 ADC 通道、往缓冲区写 N 个字节、延时循环 —— 因为**次数写在一行里，一眼看得清**。
- **固定次数的 `for` 编译器还能优化**：次数是常量时编译器可能直接**展开循环**（unroll），省掉循环开销 —— 这是嵌入式里 `for (i = 0; i < 4; i++)` 比 `while` 更受欢迎的原因之一（结构清晰 + 好优化）。
- **`for (;;)` 就是"死循环"**（等价于 `while (1)`）—— 三个位置全空。单片机主循环常见写法：`for (;;) { 干活(); }`。
- **⚠️ 延时循环的坑**：用 `for (i = 0; i < 1000; i++);` 做延时的代码，一旦编译器优化等级变了（`-O2` 可能把空循环删掉），延时就不准了 —— 正确做法是用硬件定时器或者 `volatile`。等学 `volatile` 再回头看这条。
- **溢出在嵌入式里是真事故**：`int` 阶乘溢出只是算出错值；但如果是**传给电机的 PWM 占空比**溢出成负数，可能直接烧管子。**"这个变量最大能到多少"** 是嵌入式工程师必须随手能答的问题。
