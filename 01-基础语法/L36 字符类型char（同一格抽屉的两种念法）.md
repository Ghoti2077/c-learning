## 1. 打比方：char 是"一格抽屉"

`char` 只占 **1 字节**。抽屉里装的**永远是数字**（0~255）。所谓"字符"只是给某些数字定的**外号**：

| 抽屉里的数字 | 外号 |
|---|---|
| 65 | `'A'` |
| 97 | `'a'` |
| 48 | `'0'` |
| 32 | 空格 |

**同一格抽屉，两种念法**：`%d` = 当**数字**念，`%c` = 当**字符**念。

> 💡 跟 L33「同一串位，当 signed 念 / 当 unsigned 念」是**同一个思想** —— 位没变，变的是读法。C 里到处是这一套。

## 2. 实测程序 + 真实输出

```c
#include <stdio.h>

int main(void)
{
    /* 1. char 是整数：同一格抽屉，两种念法 */
    char c = 'A';
    printf("1)  'A' 当数字=%d   当字符=%c\n", c, c);
    printf("2)  'a'=%d  'A'=%d  '0'=%d  '1'=%d  ' '=%d\n", 'a', 'A', '0', '1', ' ');

    /* 2. 字符能算数 */
    c++;                      /* 'A' 往后数一个 */
    printf("3)  'A'+1 = %c\n", c);
    printf("4)  'Z'-'A' = %d\n", 'Z' - 'A');
    printf("5)  '7'-'0' = %d   (字符数字变真数字)\n", '7' - '0');

    /* 3. 大小写转换 */
    char up = 'G', low = 'm';
    printf("6)  'a'-'A' = %d\n", 'a' - 'A');
    printf("7)  大写 %c -> 小写 %c\n", up, up + 'a' - 'A');
    printf("8)  小写 %c -> 大写 %c\n", low, low + 'A' - 'a');

    /* 4. char 也有范围，也会绕圈 */
    char big = 127;
    big++;
    printf("9)  (char)127 再加 1 = %d\n", big);

    /* 5. 同一个字符，两种印法 */
    char one = '1';
    printf("10) 字符 '1' 的码=%d，当字符印=%c\n", one, one);
    return 0;
}
```

```
1)  'A' 当数字=65   当字符=A
2)  'a'=97  'A'=65  '0'=48  '1'=49  ' '=32
3)  'A'+1 = B
4)  'Z'-'A' = 25
5)  '7'-'0' = 7   (字符数字变真数字)
6)  'a'-'A' = 32
7)  大写 G -> 小写 g
8)  小写 m -> 大写 M
9)  (char)127 再加 1 = -128
10) 字符 '1' 的码=49，当字符印=1
```

**逐条看：**

- **第 1、2 行**：`'A'` = 65，`'a'` = 97，**`'0'` = 48（不是 0！）**，`'1'` = 49，空格 = 32 —— 本课最多人栽的就是 `'0'`
- **第 3 行**：`'A'+1 = 'B'` —— ASCII 表里**字母连续排**，往后数一个就是下一个字母
- **第 4 行**：`'Z'-'A' = 25` —— **两个字符相减 = 它们在表中的距离**
- **第 5 行**：**`'7'-'0' = 7`** ← 超实用套路：**字符数字 → 真数字**，就靠减 `'0'`
- **第 6~8 行**：`'a'-'A' = 32` 是**固定值**（大写段与小写段的距离）→ **+32 变小写、-32 变大写**
- **第 9 行**：`char` 也是 8 位，范围 **-128~127**，127 再加 1 **绕圈**变 -128（L28 那套）

## 3. 本课最值钱的坑：混合输入（课件第 3 张"有何不同"的答案）

```c
#include <stdio.h>
int main(void){
    int i; char c;
#ifdef WITH_SPACE
    scanf("%d %c", &i, &c);        /* %c 前面有一个空格 */
#else
    scanf("%d%c", &i, &c);         /* %c 前面没有空格 */
#endif
    printf("i=%d  c=[%c]  c的码=%d\n", i, c, c);
    return 0;
}
```

**真实输出**（4 组，输入从管道喂）：

```
scanf("%d %c")  输入 12A    ->  i=12  c=[A]  c的码=65
scanf("%d %c")  输入 12 A   ->  i=12  c=[A]  c的码=65
scanf("%d%c")   输入 12A    ->  i=12  c=[A]  c的码=65
scanf("%d%c")   输入 12 A   ->  i=12  c=[ ]  c的码=32   ← ❌ 吃到的是空格！
```

**规律（必背）：**

1. **`%d`、`%f` 会自动跳过前面的空格 / 回车 / 制表符**
2. **`%c` 不跳！** 你给什么它收什么 —— **空格也是字符**（码 32）
3. 所以想让 `%c` 跳掉空白，就**在格式串里显式写一个空格**：`"%d %c"`
4. 4 组里**唯一不同的就是最后一组** —— 差别只在「输入里有没有空格」+「格式串里有没有空格」

**另一个必踩的坑**（同法实测）：

```c
scanf("%d", &i);      /* 只读走数字，回车留在缓冲区 */
scanf("%c", &c);      /* 这个 %c 就把回车吃进去了 */
```
```
输入 12 回车 A  ->  i=12  c=[\n]  c的码=10
```
修法同上：`scanf(" %c", &c);`（**前面加个空格**）。

## 4. 课件第 2 张那两行，说清楚

想给 `char c` 装上**字符 `'1'`**，两条路：

| 写法 | 你要输入什么 | 为什么 |
|---|---|---|
| `scanf("%c", &c);` | 敲 **`1`** | 直接当字符收 |
| `scanf("%d", &i); c = i;` | 敲 **`49`** | 走数字那条路，而 `'1'` 的码是 49 |

课件那个 `—>49` 就是这个意思。

## 5. 复习题（他的答案 + 讲评，2026-10-04）

> [!question]- Q1：`char c = 'A'; c = c + 2; printf("%c\n", c);` 输出什么？为什么？
>
> **他答**：「C，符号 A 的 ASCII 向后两位就是 C」
> **判定**：✅ 对
> **答**：输出 `C`。`'A'` 是 65，`65+2 = 67`，67 号字符是 `'C'` —— **字符能当数字加减，靠的是 ASCII 表里顺序排列**。

> [!question]- Q2：`'0'` 用 `%d` 打印是几？`'A'` 呢？
>
> **他答**：「48，65」
> **判定**：✅ 对
> **答**：`'0'` = **48**（不是 0！），`'A'` = 65。

> [!question]- Q3：怎么把字符 `'8'` 变成真正的数字 8？
>
> **他答**：`'8'-'0'`
> **判定**：✅ 对
> **答**：`'8' - '0'` = `56 - 48` = `8`。这是**最常用的套路**，串口解析天天用。

> [!question]- Q4（拐弯）：`char c = '9' - '0';` 之后 `printf("%c", c)` 和 `printf("%d", c)` 分别输出什么？
>
> **他答**：「空格和九」
> **判定**：⚠️ **一半对** —— 数字 `9` 对了；**但字符不是空格，是制表符 `\t`（TAB）**。
> **答**：`%d` 输出 **`9`**；`%c` 输出 **一个制表符**（光标右跳一下，看着像"空白"，所以容易被叫成空格）。
> **实测证据（L37 程序里跑过）**：
> ```
> 2) 当字符 = [	]   <- 方括号里那个就是 TAB
> 3) 空格码=32   tab 码=9
> ```
> **为什么不是空格**：空格是 **32** 号字符，`\t` 是 **9** 号。`'9'-'0'` 得到的是 **9**，所以 `%c` 印出来的是 9 号字符 = **TAB**。这两个都"看不见"，但**码值差 23**，别混。

## 6. 🔌 嵌入式视角

串口收到的一串数据**天生就是 char**：

```c
char c = 收到的一个字节;
if (c >= '0' && c <= '9') { int n = c - '0'; /* 字符数字变数字 */ }
if (c == '\n') { /* 一行收完了 */ }
```

解析 AT 指令、读传感器发来的数值、判断帧头帧尾 —— 全是这套。**`c - '0'` 这个套路以后每天都会打。**

## 7. 一句话总结

**char 是一格抽屉，里面永远是数字；`%c` 是按"外号"念、`%d` 是按"数字"念。字符能加减（间距 32 管大小写、减 `'0'` 管数字转换），但 `%c` 输入时不会自己跳过空格和回车 —— 这是它最坑的地方。**
