## 1. printf 和 stdio.h 到底是什么关系

先看一句完整的"开场白"：

```c
#include <stdio.h>

int main()
{
    printf("hello C\n");
    return 0;
}
```

拆成两个角色：

| 东西 | 角色 | 干啥的 |
|---|---|---|
| `stdio.h` | **说明书 / 清单** | 里面写着"我这有 printf、scanf 这些工具，它们长什么样" |
| `printf` | **工具本身** | 真正干活的那个函数（代码在库文件里） |
| `#include <stdio.h>` | **把清单抄过来** | 不抄，编译器就不认识 printf，直接报"未声明" |

> 比方：`stdio.h` 是仓库门口的**货物清单**，`printf` 是仓库里的**那把锤子**。
> `#include` = 你把清单抄一份放桌上，编译器一看清单："哦，有锤子这东西" → 后面才允许你用。
> 不抄清单直接喊"拿锤子"，编译器的反应是：**"锤子是啥？没听说过。"**（报 `未声明的标识符`）

**`.h` 是文件后缀**，表示 header（头文件）。**少了 `.h` 编译不过**，因为系统里根本不存在叫 `stdio` 的文件——只有 `stdio.h`。

## 2. stdio 这四个字母怎么来的

```
std = standard  标准
i   = input     输入
o   = output    输出
.h  = header    头文件后缀

stdio.h = 标准输入输出头文件
```

- **输入** = 程序从外面拿东西进来（键盘打字、串口收数据）
- **输出** = 程序把东西送出去（屏幕上显示、串口发出去）
- 所以 `printf`（print formatted，带格式地打印）住在 `stdio.h` 里——它是管**输出**的。后面要学的 `scanf` 管输入，也住这儿。

> ⚠️ 拼写记牢：**s-t-d-i-o**，五个字母，**没有 a**。写成 `stadio` 编译器会说：
> `fatal error: stadio.h: No such file or directory`（没有这个文件 → 因为我抄错名字了）

## 3. 占位符 `%d` 怎么用

**占位符 = 一个"先占住位置的空位"，等会儿把真东西填进去。**

```c
int ban = 5;
printf("ban = %d\n", ban);        // %d 这个空位被 ban 的值填上
printf("%d + %d = %d\n", 3, 4, 3 + 4);
```

**实跑结果**（我编了一遍，不是猜的）：

```
ban = 5
3 + 4 = 7
```

规则三条：

1. **`%d` 在字符串里占位**，字符串外面用逗号跟上要填的值。
2. **前后顺序一对一**：第一个 `%d` 吃第一个值，第二个吃第二个，不能乱。
3. **`%d` 只给整数用**；小数要用 `%f`（以后学）。

⚠️ **别写成 `#d`**。`%` 和 `#` 两个符号完全不同的活：

| 符号 | 名字 | 干啥的 |
|---|---|---|
| `%d` | 占位符 | 在 printf/scanf 里**占一个位置**等着填值 |
| `#` | 预处理符号 | 出现在**行首**，引导 `#include`、`#define` 这类"给编译器的话" |

## 4. 库函数 vs 头文件 vs 库文件（一次搞清）

| 名词 | 里面装的是 | 比方 |
|---|---|---|
| **库函数** | 别人写好的、能直接用的函数（printf、scanf…） | 仓库里的工具 |
| **头文件 `.h`** | 这些函数的**声明**（名字、参数、返回值） | 货物清单 / 说明书 |
| **库文件 `.lib`/`.a`/`.dll`** | 这些函数的**真正代码** | 工具本身（真锤子） |

> 一句话：**头文件只管"你有没有这个工具"，库文件才是"工具本体"。**
> 你写 `#include` 是抄清单；链接的时候编译器才去仓库把真工具搬过来（这也是上一课"链接错误"的来源）。

## 5. 标识符（名字）的规矩

**标识符 = 你自己起的名字**（变量名、函数名都算）。规矩：

| 规矩 | 对 | 错 |
|---|---|---|
| 只能用 **字母、数字、下划线_** | `my_age`、`a1` | `my-age`、`my age`、`my.age` |
| **不能以数字开头** | `a1` | `1a` ❌ |
| **不能和关键字重名** | `ban`、`count` | `int`、`return`、`if`、`for` ❌ |
| **区分大小写** | `Age` 和 `age` 是两个不同的名字 | 别以为一样 |
| 不能用中文/全角 | `ban` | `变量`、`ｂａｎ` ❌ |

**关键字（保留字）** = C 语言自己先占了的词，如 `int`、`return`、`if`、`while`、`for`、`void`…… 你**不能**把它们抢来当名字。我笔记里写的"return 是保留字"就是这个意思，标准叫法是**关键字**。

## 6. `int ban;` 到底创建了什么（这处错要重点纠正）

我原来写：「`int ban;` 可以创建一个 int 类型的**函数名**」——**错，它创建的是变量。**

```c
int ban;        // ← 变量！一个叫 ban 的整数盒子
int ban();      // ← 这才是函数（声明）：有 name + 括号
```

**区分的唯一标志：有没有 `( )`。**

- 有 `( )` = **函数**（一段会干活的代码）
- 没有 `( )` = **变量**（一个装东西的盒子）

我把变量当函数调用，编译器直接骂了（实跑原文）：

```
error: called object 'ban' is not a function or function pointer
       int ban = 5;   ← 编译器还贴心地标出：它在这儿被声明成了一个变量
```

翻译成人话：**"`ban` 不是函数，你对着它喊什么？"**

> 比方：`ban` 是个**盒子**，`ban()` 才是**按按钮**。对着盒子按是按不动的。

## 7. 完整例子（手打，不许复制）

```c
#include <stdio.h>

int main()
{
    int ban = 5;
    printf("我们班有 %d 个人\n", ban);
    printf("%d 加 %d 等于 %d\n", 3, 4, 3 + 4);
    return 0;
}
```

**实跑结果**：

```
我们班有 5 个人
3 加 4 等于 7
```

> 注意：**字符串里的中文完全可以用**（`"我们班有"`），只有**语法符号**（`#` `<` `>` `"` `(` `)` `;` `%`）必须英文。

### 补充一个重要纠正：`#include` 不是"抽象地列举"，是**把整页文字原样抄进来**

我说的"清单"只是个比方，**实际动作比这个粗暴**：编译器开工前有个叫**预处理器**的环节，它做的事就是——把你的 `#include <stdio.h>` 这一行**整行删掉**，然后把 `stdio.h` 那 894 行内容**一个字不改地粘到这儿**。

我实测了一下（真的跑了预处理器 `gcc -E`）：

| | 行数 |
|---|---|
| 我自己写的文件 `inc.c` | **7 行** |
| 预处理之后 | **1805 行** |
| 我的 `int main()` 跑到了 | **第 1801 行** |

也就是说：我写的两行代码被顶到了 1801 行，前面 1800 行全是 `stdio.h` 抄进来的内容。**这就是 `#include` 干的全部事情——纯粘贴。**

### 顺带回答我笔记里自己的疑问：头文件里的"声明"到底长什么样

我把 `stdio.h` 打开看了，`printf` 在**第 300 行**，就一行：

```c
int  printf (const char *__format, ...)
```

念一遍：**`int`（我返回一个整数）+ `printf`（我叫 printf）+ `(const char *__format, ...)`（你得给我一个字符串，后面还要几个东西）**

- **`;` 都没写**（声明结尾只有分号，这里是简化的头文件写法）——注意：**声明没有 `{ }` 函数体**，因为它只是"预告"，不是干活的代码。
- **`...`** 表示"后面还能跟任意多个值"——这就是为什么 `printf("%d %d", 10, 20)` 能塞好几个参数。
- 真干活的代码不在头文件里，在编译好的**库文件**里。头文件只负责"告诉编译器有这么个东西"。

> 一句话对比：
> **声明** = 菜单上写着"有红烧肉这道菜" → 头文件
> **定义/实现** = 厨房里真在做这道菜 → 库文件
> 点菜（调用）之前得先看到菜单，这就是为什么必须 `#include`。

### 现在你已经有能力看懂整个流程了（四步流水线）

| 步骤 | 谁在干 | 干的事 | 出错长什么样 |
|---|---|---|---|
| 1 预处理 | 预处理器 | 抄头文件、删注释、展开 `#define` | `fatal error: xxx.h: No such file or directory` |
| 2 编译 | 编译器 | 把 C 代码翻译成机器码（.obj） | `error C2143: 语法错误` 这类 |
| 3 汇编 | 汇编器 | 变成二进制目标文件 | 少见 |
| 4 链接 | 链接器 | 把库文件、其他 .obj 拼成一个 exe，找 `main` | `LNK2019 无法解析的外部符号` |

> 所以：**拼错头文件名 → 第 1 步就死；语法写错 → 第 2 步死；少个函数实现/没有 main → 第 4 步才死。** 报错在哪一步，你就知道该往哪儿找问题。
