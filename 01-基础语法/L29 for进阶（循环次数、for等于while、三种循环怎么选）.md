# L29 `for` 进阶：次数、等价、怎么选

- 日期：2026-09-21
- 来源：翁恺《C语言程序设计》for 循环（课件 5 张：循环次数 / for==while / 表达式可省略 / 三种循环流程图 / Tips for loops）
- 标签：`#C语言` `#基础语法` `#循环` `#for`

> **一句话总结**：
> **`for` = 把 `while` 的三个零件收进一行**（`for == while`）；
> **想数清循环跑几次，只要数"有几个 `i` 满足条件"**，**结束后的 `i` 就是"第一个不满足条件的值"**；
> **三个表达式都能省略**，`for (;条件;)` 就是 `while (条件)`，而 `for (;;)` 是**死循环**。
> **怎么选**：固定次数 → `for`；至少做一次 → `do-while`；其他 → `while`。

## 1. 循环次数怎么数（课件 + 我的实测）

![[L29-课件 循环次数.png]]

课件说的是 `for (i=0; i<n; i++)`：**循环 n 次，结束后 `i` 的值是 n** ✅（我实测对上了）。
但它留了一句话更关键：**"从 0 还是从 1 开始、判断 `<` 还是 `<=`，对次数和结束值都有影响"**。

**四种写法全实测**（n = 5）：

| 写法 | 做了几次 | 结束后 `i` |
|---|---|---|
| `for (i = 0; i < n; i++)` | **5 次** | `i = 5` |
| `for (i = 0; i <= n; i++)` | **6 次** | `i = 6` |
| `for (i = 1; i <= n; i++)` | **5 次** | `i = 6` |
| `for (i = 1; i < n; i++)` | **4 次** | `i = 5` |

### 两条万能规律（不用背表）

> ① **循环次数 = "有几个 `i` 满足条件"**
> ② **结束后的 `i` = "第一个不满足条件的值"**

**验证给 `n = 5`**：

| 写法 | 满足条件的 `i` 有哪几个 | 个数=次数 | 第一个不满足的 `i` |
|---|---|---|---|
| `i=0; i<5` | 0,1,2,3,4 | **5** | 5 |
| `i=0; i<=5` | 0,1,2,3,4,5 | **6** | 6 |
| `i=1; i<=5` | 1,2,3,4,5 | **5** | 6 |
| `i=1; i<5` | 1,2,3,4 | **4** | 5 |

**记忆口诀**：
**"`<` 是差一个，`<=` 是齐平"** —— `i<n` 时 `i` 数不到 `n`（少一个）；`i<=n` 时能数到 `n`（齐）。
**而结束值永远比"最后一个进过循环的 `i`"大 1**（因为退出前那一步进已经执行过了，L27 实测过）。

## 2. `for` 和 `while` 完全等价

![[L29-课件 for等于while（对照+流程图）.png]]

```c
for (int i = 1; i <= n; i++) {      /* 三件套在一行 */
    fact *= i;
}
```
```c
int i = 1;                          /* 初始化搬到循环前 */
while (i <= n) {                    /* 条件放进 while 括号 */
    fact *= i;
    i++;                            /* 步进塞进循环体最后 */
}
```

**两者的流程图一模一样**：`初始化 → 检查条件 →(是) 做循环体 → 做步进 → 回到检查条件`；条件不满足就直接走人。

**为什么工程上更爱用 `for`**：
- 三个零件在一行，**扫一眼就知道"从几跑到几、怎么变"**；
- **不容易忘写步进**（忘了 `i++` → 死循环，这是 `while` 最常见的翻车方式）。

## 3. 三个表达式都能省略（课件 + 实测）

![[L29-课件 for的表达式可以省略.png]]

```c
for ( ; 条件 ; )        /* 等价于 while (条件) —— 实测确实一样 */
for ( ; ; )             /* 三个都省 → 条件永远为真 → 死循环 */
```

**实测 `for (; i < 7; )`**（初始化已经做过、步进写进循环体）：

```
等价于 while (i<7)：做 2 次，结束后 i = 7
```

**实测 `for (i = 0; ; i++)`**（省略条件）：跑了 **10 亿次还没停** —— 只能靠 `break` / `return` 出来，否则程序永不结束（这就是 L23 说的"死循环"）。

**缺哪个位置就会缺什么**：

| 省略 | 后果 |
|---|---|
| 省**初始化** | 得在外面先赋好值（`int i = 1;` 写在前面），否则 `i` 是随机值 → 次数不可控 |
| 省**条件** | **条件永远真 → 死循环**（只能 `break` 出来） |
| 省**步进** | `i` 永不变化 → 条件永远成立 → **死循环** |

**工程惯例**：`for (;;)` 只在**故意要死循环**时写（单片机主循环就是它）；日常代码**三个位置都写满**。

**顺带一个有用的写法**：步进位置可以写**多个动作**（逗号隔开），实测正常：

```c
for (i = 0; i < 3; i++, cnt++) { ... }     /* 每轮 i++ 和 cnt++ 都做 */
```

## 4. 三种循环怎么选（课件的 Tips）

![[L29-课件 Tips for loops（怎么选循环）.png]]

![[L29-课件 三种循环的流程图.png]]

| 情况 | 用哪个 | 理由 |
|---|---|---|
| **有固定次数**（"做 10 次"、"扫 8 个灯"） | **`for`** | 次数写在一行里，一目了然 |
| **必须执行一次**（至少要读一个输入/发一次命令） | **`do-while`** | 先做再判断（L24） |
| **其他**（"直到某件事发生"） | **`while`** | 条件成立才做，可能一次都不做 |

**三条流程图的形状对照**（看"判断框在哪"就知道区别）：

| 循环 | 判断框位置 | 循环体最少执行 |
|---|---|---|
| `for` / `while` | 循环体**之前** | **0 次** |
| `do-while` | 循环体**之后** | **至少 1 次** |

## 5. 复习题（先自己答）

1. `for (i = 1; i < n; i++)`（`n = 10`）会做几次？结束后 `i` 是几？
2. `for (i = 0; i <= n; i++)`（`n = 10`）会做几次？
3. 把 `for (i = 1; i <= n; i++) { fact *= i; }` 改成两个表达式都省略的写法（初始化在外面），怎么写？
4. 我写 `for (i = 0; i < n; )` 忘了写步进，程序会怎样？为什么？
5. 三种循环分别什么场合用？各举一个我们做过的例子。

> [!question]- 参考答案（先自己答完再点开）
>
> 1. 满足条件的是 1~9 共 **9 个** → 做 **9 次**；结束后 `i` 是**第一个不满足的 10**。
> 2. 满足条件的是 0~10 共 **11 个** → 做 **11 次**。（`<=` 是"齐平"，把 `n` 也算进去了）
> 3. ```c
>    int i = 1;
>    for ( ; i <= n ; ) {
>        fact *= i;
>        i++;              /* 步进搬进循环体 */
>    }
>    ```
>    （三个位置全空也行，但那样条件永远真就成了死循环，必须靠 `break` 出去）
> 4. **死循环**（程序卡住不结束）。因为 `i` 永远不变，`i < n` 永远成立；而且 `for (i=0; i<n; )` 这种写法**编译器不报错也不警告**，只能靠自己看。
> 5. **固定次数 → `for`**（比如"打印 1~n"、"扫 8 个数码管"）；**必须执行一次 → `do-while`**（输入检查、猜数游戏先猜一次、数位数保证至少算一位）；**其他 → `while`**（数位数 `while (x>0)`、倒计时到条件不成立为止）。

## 6. 嵌入式视角

- **固定次数的 `for` 是嵌入式的默认写法**：`for (i = 0; i < 8; i++)` 扫 8 位数码管、`for (i = 0; i < 4; i++)` 读 4 路 ADC。**次数是常量时编译器还能直接把循环展开**（unroll），省掉计数和跳转的开销。
- **`for (;;)` 就是单片机的主循环**：嵌入式程序通常永不退出，写成 `int main(void) { 初始化(); for (;;) { 干活(); } }` —— 这里"死循环"是**设计**，不是 bug（PC 上则是灾难）。
- **"次数来自变量"时要格外小心**：`for (i = 0; i < n; i++)` 里的 `n` 若来自传感器/串口，**`n` 必须是可信值**，否则可能：
  - `n` 过大 → 循环跑太久 → **看门狗复位**（相当于单片机的"TLE"）；
  - 数组删除/写入越界 → 踩坏内存。
  工程上常先做**范围钳制**（`if (n > MAX) n = MAX;`）再进循环。
- **循环次数的"结束值"在嵌入式里也常被利用**：`for` 结束后 `i` 正好等于"处理过的元素个数"，直接拿来当下标用很常见（但要知道它比最后一个下标大 1，别越界）。
