## 1. 两个比方（记住这两句就够）

**比方一：听谁的大。——做运算时，编译器先看两边各是什么类型，谁的范围大就按谁的规矩算。**

`int + double` → 按 `double` 算（int 被"抬高"成 double）。

**比方二：先算，再装。——右边的算式怎么算，跟你把它装进哪个类型的盒子里一点关系都没有。**

左边写 `double d = 5 / 2;` —— 左边是 double **没用**，右边 `5` 和 `2` 都是 int，就先按整数算得 `2`，**再**装进 double 变成 `2.0`。

> 💡 这一条就是 L31 那个 `sum += 1 / i` 全场变 0 的**病根**：`1` 和 `i` 都是 int → 先整除 → `1/2 = 0`、`1/3 = 0`…全 0，加进去当然还是 0。写 `1.0 / i` 才让右边变成浮点运算。

## 2. 实测程序 + 真实输出（源码照抄，可自己编译）

```c
#include <stdio.h>

int main(void)
{
    /* 1. 两个整数相除 = 整除（丢小数） */
    printf("1)  1 / 2        = %d\n", 1 / 2);
    printf("2)  3 / 2        = %d\n", 3 / 2);
    printf("3)  1 / 3        = %d\n", 1 / 3);
    printf("4)  1.0 / 2      = %f\n", 1.0 / 2);
    printf("5)  1.0 / 3      = %.10f\n", 1.0 / 3);

    /* 2. 关键：先算，再存 */
    double d1 = 5 / 2;      /* 右边先按整数算 = 2，再存进 double */
    double d2 = 5.0 / 2;    /* 右边按浮点算 = 2.5 */
    printf("6)  double d = 5 / 2    -> %.1f\n", d1);
    printf("7)  double d = 5.0 / 2  -> %.1f\n", d2);

    /* 3. 强制转换的位置差别 */
    printf("8)  (double)5 / 2   = %.1f\n", (double)5 / 2);    /* 只转 5 */
    printf("9)  (double)(5 / 2) = %.1f\n", (double)(5 / 2));  /* 先算完再转 */

    /* 4. 小数 -> 整数：截断（向零取整），不是四舍五入 */
    printf("10) (int)3.9        = %d\n", (int)3.9);
    printf("11) (int)-3.9       = %d\n", (int)-3.9);
    printf("12) (int)(3.9 + 0.1)= %d\n", (int)(3.9 + 0.1));

    /* 5. 取余 % 只能给整数 */
    printf("13) 10 / 4 = %d ,  10 %% 4 = %d\n", 10 / 4, 10 % 4);

    /* 6. 塞不下就截断（大盒子 -> 小盒子） */
    int big = 300;
    char ch = (char)big;
    printf("14) (char)300       = %d\n", ch);

    short s = 32768;        /* 故意溢出 */
    printf("15) short 32768     = %d\n", s);

    /* 7. 表达式自己的类型 */
    printf("16) sizeof(1 / 2)   = %d   sizeof(1.0 / 2) = %d\n",
           (int)sizeof(1 / 2), (int)sizeof(1.0 / 2));

    /* 8. 左结合 */
    printf("17) 7 / 2 * 2.0     = %.1f\n", 7 / 2 * 2.0);
    printf("18) 7.0 / 2 * 2     = %.1f\n", 7.0 / 2 * 2);
    return 0;
}
```

**真实输出**（`gcc 16.2.0`，`gcc -Wall` 编译 **0 错误 0 警告**）：

```

6)  double d = 5 / 2    -> 2.0   (先整除)
7)  double d = 5.0 / 2  -> 2.5
8)  (double)5 / 2   = 2.5

10) (int)3.9        = 3
```

## 3. 逐条看（哪条最坑）

### ① 第 1~3 行：两个 int 相除 = **整除**（小数直接扔，不是四舍五入）

`1/2 = 0`、`3/2 = 1`、`1/3 = 0`。想让结果带小数，**至少一边得写成小数**（第 4、5 行的 `1.0`）。

### ② 第 6、7 行：**本课核心 —— 先算，再装**

- `double d1 = 5 / 2;` → 右边两个都是 int → 先算出 `2` → 再装成 `2.0` ❌
- `double d2 = 5.0 / 2;` → 右边有小数 → 按浮点算 → `2.5` ✅

**左边变量的类型管不了右边的算式。**

### ③ 第 8、9 行：`(类型)` 只管它**右边挨着的第一个东西**

| 写法 | 过程 | 结果 |
|---|---|---|
| `(double)5 / 2` | `5` 先变 `5.0` → `5.0/2` | **2.5** ✅ |
| `(double)(5 / 2)` | 括号里先按整数算出 `2` → 再转成 `2.0` | **2.0** ❌ 白转 |

### ④ 第 10~12 行：小数 → 整数是**截断**（往 0 砍），不是四舍五入

- `(int)3.9 = 3`
- **`(int)-3.9 = -3`** ← 注意！是 **-3**，不是 -4（往 0 的方向砍，不是往下）
- `(int)(3.9 + 0.1) = 4` ← 括号里先算成 `4.0` 再截

**想四舍五入得自己写**：`(int)(x + 0.5)`。

### ⑤ 第 13 行：`%` 取余**只能给整数**，浮点用不了

`10/4 = 2`、`10%4 = 2` —— 一个给商、一个给余数。

### ⑥ 第 14、15 行：塞不下就**绕圈**（L28 学过的那套）

- `char` 只有 8 位（-128~127），放 300 → `300 - 256 = ` **44**
- `short` 上限 32767，`32768` 越界 → **-32768**（待办本里记的正是这条，今天实测坐实）

### ⑦ 第 16 行：**算式自己就有类型**（最硬的证据）

`sizeof(1 / 2) = 4`（int）、`sizeof(1.0 / 2) = 8`（double）。

**写在纸上的算式本身是有类型的**，跟左边变量是谁毫无关系 —— 这就是"先算再装"的物理证据。

### ⑧ 第 17 行：左结合，从左往右算

`7 / 2 * 2.0` → 先 `7/2 = 3`（整除！）→ 再 `3 * 2.0 = ` **6.0** ❌
想对就得先转：`7.0 / 2 * 2` = **7.0** ✅

---

## 4. 三条必背

1. **两个 int 相除 = 整除**（扔小数）。要小数，至少一边写成 `1.0`、`5.0`。
2. **先算，再装** —— 左边变量的类型管不了右边怎么算。`double d = 5/2` 就是 `2.0`。
3. **`(类型)` 只管右边挨着的第一个东西**；小数→整数是**截断**（`(int)-3.9 = -3`，往 0 砍）。

## 5. 复习题（他的答案 + 讲评，2026-10-04）

> [!question]- Q1：`int a = 5, b = 2; double c = a / b;` 打印 `c` 是多少？为什么？
>
> **他答**：「2.0，因为计算机先计算了 A÷B，再把它转化成 double 的形式，而 A÷B 的结果是 2」
> **判定**：✅ **满分** —— 把"先算再装"说得一字不差。
> **答**：`2.0`。`a` 和 `b` 都是 int → 先按整数算出 `2` → 才装进 `c`（double）。左边写 double 救不了右边的算式。

> [!question]- Q2：`(int)5.99` 和 `(int)-5.99` 分别输出几？
>
> **他答**：「五和负五」
> **判定**：✅ 对（5 和 -5）
> **答**：`5` 和 **`-5`**。截断 = **往 0 的方向砍**，不是四舍五入、也不是"往下取整"。`-5.99` 砍掉尾巴是 `-5`。

> [!question]- Q3：`7 / 2 * 2.0` 和 `7.0 / 2 * 2` 分别是多少？
>
> **他答**：「6.0 和 7」
> **判定**：⚠️ **数值对，但有一处要收紧** —— 第二个的结果是 **`7.0`（浮点）**，不是整数 `7`。
> **答**：`6.0`（先 `7/2 = 3` 整除，再 `3*2.0`）和 `7.0`（`7.0/2 = 3.5`，`3.5*2 = 7.0`）。
> **为什么揪这个**：类型不一样，用 `printf("%d", ...)` 去印浮点会打出垃圾 —— 数值对不代表类型对，**心里要带上"它是浮点"**。

## 6. 🔌 嵌入式视角（以后在单片机哪里用得上）

**ADC 采电压的经典翻车现场**（上板第一周必踩）：

```c
float v = adc / 4095 * 3.3f;        /* ❌ adc 是 int（比如 0~4095）→ adc/4095 几乎永远是 0 → v 全 0 */
float v = (float)adc / 4095 * 3.3f; /* ✅ 先把 adc 转成 float，再做除法 */
```

- ADC 读出来的是 **int**（12 位分辨率 = 0~4095），要换算成电压必须**先转 float**，否则整除把小数全砍了 → 串口打出来一排 0
- 另一类常见处：**算平均值** `sum / count`（两个 int）→ 温度/电压平均值全是整数，小数丢了 → 写 `(float)sum / count`
- 和 L28 对照记：**大盒子→小盒子的隐式转换编译器不一定警告**，但值已经绕圈了（`char` 装 300 → 44），上板看传感器数据变负、变怪，先想想是不是类型塞不下

## 7. 一句话总结

**C 的运算规矩：「谁范围大听谁的」+「先算，再装」—— 两个 int 相除就是整除，左边写什么类型都救不回右边；要小数，就把算式里至少一个数写成小数，或者用 `(类型)` 把它转过去。**
