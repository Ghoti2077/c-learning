# L30 `break` vs `continue` + 素数判断

- 日期：2026-09-21
- 来源：翁恺《C语言程序设计》break vs continue（课件）+ 我自己读的素数判断程序
- 我的理解（原话）：「continue 是跳过后面的语句重新回到循环头做步进，break 是跳出循环」
- 标签：`#C语言` `#基础语法` `#循环` `#break` `#continue`

> **一句话总结**：
> **`break` = 直接掀桌走人**（跳出整个循环）；**`continue` = 这一轮不干了，回去开下一轮**（跳过本轮剩下语句）。
> ⚠️ **"回去做步进"这句话只对 `for` 成立！** 在 `while` 里，步进（`i++`）写在循环体里，
> **会被 `continue` 一起跳过 → `i` 不变 → 死循环**（这是最经典的 continue 翻车现场，下面有实测）。

---

## 1. 课件：break vs continue

| 语句 | 作用 |
|---|---|
| **`break`** | **跳出循环**（这一轮剩下的、后面所有轮次，全都不做了） |
| **`continue`** | **跳过本轮剩下的语句，进入下一轮** |

**打比方**：
- `break` 像**上课直接跑出教室**——后面的课也不上了；
- `continue` 像**这一道题跳过，继续做下一题**——人还在循环里。

## 2. 我的理解核对（continue 那句要修正）

| 我说的 | 判定 |
|---|---|
| 「`break` 是跳出循环」 | ✅ 完全正确 |
| 「`continue` 跳过后面的语句重新回到循环头**做步进**」 | ⚠️ **只对 `for` 成立，对 `while` 是坑**（`while` 没有"步进位置"，见第 3 节实测） |

**为什么会差**：`for` 的步进写在**圆括号第三格**里，`continue` 跳不到它；
`while` 的步进（`i++`）是**循环体里的一行普通代码**，`continue` 一跳就把它跳掉了。

## 3. 实测三种情况

### ① `for` + `continue`（正常）

```c
for (int i = 0; i < 5; i++) {
    if (i == 2) continue;
    printf("  i = %d\n", i);
}
```

实测输出：`0 1 3 4`，**然后正常结束** ✅ —— 跳过 `i=2` 那一轮，但 `i++` 照做，所以不会卡死。

### ② `while` + `continue` 写错（死循环！）

```c
int i = 0;
while (i < 5) {
    if (i == 2) continue;      /* 跳回条件检查 */
    printf("  i = %d\n", i);
    i++;                       /* ← 这行被 continue 跳过了 */
}
```

实测输出：`0 1` 然后**卡死**（限时 3 秒被强制砍掉，退出码 124）❌

**原因**：`i` 到 2 时 `continue` → 直接回去检查 `i < 5`（还是 2，还是成立）→ 又进来 → 又 `continue`…… **`i++` 永远轮不到** → 死循环。

### ③ `while` + `continue` 正确写法（步进提前）

```c
int i = 0;
while (i < 5) {
    i++;                       /* ← 步进放最前面，continue 再也跳不掉它 */
    if (i == 3) continue;
    printf("  i = %d\n", i);
}
```

实测输出 `1 2 4 5`，**正常结束** ✅

**结论（记这一条就够）**：**`while` 里要用 `continue`，就把"步进"放在 `continue` 之前**（或者改用 `for`）。

## 4. `break` / `continue` 各管哪一层（对照表）

| 语句 | 在 `for`/`while`/`do-while` 里 | 在 `switch` 里 |
|---|---|---|
| `break` | **跳出整个循环** | **跳出整个 switch**（L21 学过，别搞混） |
| `continue` | 跳过本轮剩下语句，进入下一轮 | ❌ **`switch` 里没有 continue 这个概念**（写在循环内的 switch 里，它其实是冲着**外层循环**去的） |

**都只影响"最近的那一层"**：循环套循环时，内层 `break` 只跳出内层（以后学嵌套循环再细讲）。

## 5. 我的素数判断程序核对

```c
int main() {
    int i, x;
    int isPrime = 1;
    scanf("%d", &x);
    for (i = 2; i < x; i++) {
        if (x % i == 0) {        /* 找到因子 → 不是素数 */
            isPrime = 0;
            break;               /* ✅ 提前退出，不用白跑剩下的 */
        }
    }
    if (isPrime == 1) {
        printf("是素数\n");
    }
    else {
        printf("不是素数\n");
    }
    return 0;
}
```

### ✅ 写得很好的地方

| 点 | 说明 |
|---|---|
| **`isPrime` 先假设是素数，找到因子再推翻** | 思路干净（"默认成立 + 反例推翻"是标准写法） |
| **`break` 提前跳出** ✅ | 一旦找到因子就没必要继续试 —— **这是 break 最典型的用法**（省时间） |
| 判断条件 `x % i == 0` | 直接命中"因子"的定义，`%` 用对了 |
| 两个 `printf` **都带 `\n`** ✅ | 红警见效 |
| 变量名 `isPrime` | 起得好，"是不是素数"一眼看懂 |

### ⚠️ AI 穷举核对的结果（`-5` 到 `100000` 全跑一遍）

```
不一致：x=-5 … x=1 共 7 处
-5~100000 全跑：不一致 7 处
```

**结论**：**`x ≥ 2` 全对**（十万个测试点一个不错）✅；**只有 `x ≤ 1` 判错**：

| 输入 | 我的程序输出 | 正确答案 |
|---|---|---|
| 1 | 「是素数」❌ | **1 不是素数** |
| 0 | 「是素数」❌ | 不是素数 |
| 负数 | 「是素数」❌ | 不是素数 |
| **2** | 「是素数」✅ | 是素数（循环一次没进，`isPrime` 保持 1，**刚好对**） |

**为什么**：`for (i = 2; i < x; i++)` 对 `x ≤ 1` **一次都不进**，`isPrime` 就一直是初始的 1。

**修法**（一句话）：循环后面补一条兜底：

```c
if (x < 2) {
    isPrime = 0;              /* 数学规定：小于 2 的数都不是素数 */
}
```

**教训（老规矩）**：**正常值全对，是边界值暴露问题** —— 这次又是**边界 1**（跟"0 的位数""120 逆序"同一类）。

### 💡 一个效率优化（不影响正确性）

现在试除到 `x - 1`；其实**只要试到 √x 就够了**（超过 √x 就不可能再配成因子）。
不想用开方函数的话，写成乘法判断：

```c
for (i = 2; i * i <= x; i++)      /* 效果一样，但少跑很多轮 */
```

（AI 的参考实现就是用这个写法，穷举结果和我的完全一致 ✅）

> [!question]- 参考答案（先自己答完再点开）
>
> 1. **`break` 跳出整个循环**（像直接跑出教室，后面都不上了）；**`continue` 只跳过本轮剩下的语句，进入下一轮**（像跳过这道题继续做下一题）。
> 2. 因为 `while` 的**步进（`i++`）是写在循环体里的一行**，`continue` 会把它一起跳掉 → `i` 不变 → 条件永远成立 → 死循环（实测卡死）。**改法**：把 `i++` 放到 `continue` 之前（循环体最前面），或者改用 `for`（步进在括号第三格里，跳不掉）。
> 3. 输出「**是素数**」——**错**（1 不是素数）。因为 `i = 2; i < 1` 一次都不成立，循环体没跑，`isPrime` 保持着最初的 1。修法：循环后补 `if (x < 2) isPrime = 0;`。
> 4. **能去掉，结果也一样对**（`isPrime` 一旦被置 0 就不会变回来），但**会变慢**：明明找到一个因子就能确定"不是素数"，去掉 `break` 还要把剩下的 `i` 全部试完。**`break` 在这里是纯粹的效率优化**——`break` 最典型的使用场景就是这种"提前确定答案就收工"。
> 5. **不是**。在循环里：跳出整个**循环**；在 `switch` 里：跳出整个 **switch**（L21 学过）。共同点是"**只跳出最近的那一层**"。

## 7. 嵌入式视角

- **`break` 在嵌入式里是省电/省时间的利器**：扫描数组找目标时，找到就 `break`，不用把剩下的几百个元素跑完 —— 在电池设备上这直接等于**少耗电**。
- **`continue` 常用来"过滤无效数据"**：串口/传感器收到的数据包里，校验错的直接 `continue` 丢掉，处理逻辑写在下面（保证主流程干净）。**注意用 `while` 时把步进放前面**（第 3 节的坑，硬件上卡死就是看门狗复位）。
- **`for (;;) { ... }` 主循环 + `break` 退出条件**：有些嵌入式程序的主循环里用 `break` 来"跳出到错误处理"，但**更多用 `return`/复位**——因为主循环退出去之后程序也没地方可去了。
- **素数这类"试除"算法在嵌入式里要控次数**：试除到 `√x` 的优化不是"讲究"，是**必须**——单片机上跑十万次除法是很贵的事（很多单片机没有硬件除法器，一次除法要几十个时钟周期）。
- **`switch` 里的 `break` 漏写**是嵌入式常见的真事故（穿透执行到别的分支去驱动 IO）——L21 记过这条。

## 8. 补充：`√x` 优化好在哪？（数学原因 + 实测数据）

### 先说结论

**只要有因子，试到 `√x` 一定能碰上** —— 所以这个优化**不会漏判**，但能省掉绝大部分的除法。

### 为什么（一句话证明）

**假设 `x = a × b`（a、b 都是大于 1 的因子），那么 a 和 b 里必有一个 ≤ √x。**
因为如果两个都大于 √x，那 `a × b > √x × √x = x` —— 乘积比 x 还大，矛盾。

**比方**：把 `x` 个方块摆成长方形，看有没有"另一种摆法"。
你只需要看**短边**——**短边最长只能是 √x，再长就跟已经数过的摆法重复了**（`3 × 9973` 和 `9973 × 3` 是同一种摆法，数两遍没意义）。
所以**试除只需要试"短边"**，也就是从 2 试到 √x。

**为什么写 `i * i <= x` 而不是 `i <= sqrt(x)`**：
- 不用 `#include <math.h>`、**不用浮点数**（浮点开方有精度问题，正好卡在边界上可能算错）；
- **乘法比开方快得多**（单片机上一次开方可能要几百个时钟周期，一次乘法只要几个）。
- 等价写法是 `i <= x / i`（也能避免 `i * i` 自身溢出），以后遇到大数再用。

### 实测数据（用计数器数出"到底做了多少次除法"）

| 版本 | 2~99（100 以内素数，25 个） | 2~99999 |
|---|---|---|
| **原版 `i < x`**（带 `break`） | **1132** 次除法 | **455,189,149** 次（4.55 亿！） |
| **优化版 `i * i <= x`**（带 `break`） | **235** 次 | **2,745,693** 次 |
| **去掉 `break`** | **4753** 次（原版的 **4.2 倍**） | — |

**三个数一起看更清楚**：

1. **优化 √x**：100 以内省掉 **~80%** 的除法；范围拉到 10 万时是 **165.8 倍** 的差距 —— **范围越大，优势越大**（这就是"算法"和"写法"的威力）。
2. **`break` 的价值**：去掉后除法次数涨到 **4.2 倍** —— 它省掉的是"已经确定答案之后白跑的轮次"。**两个优化是叠加的**（一个减轮数、一个提前收工）。

## 9. 我写的"100 以内素数输出"核对（嵌套循环）

```c
//素数判断+100以内素数输出
int main() {
    int x;
    //scanf("%d", &x);
    for (x = 2; x < 100; x++) {
        int i;
        int isPrime = 1;
        for (i = 2; i < x; i++) {
            if (x % i == 0) {
                isPrime = 0;
                break;
            }
        }
        if (isPrime == 1) {
            printf("%d\n", x);
        }
    }
    return 0;
}
```

### ✅ 写对的地方

| 点 | 说明 |
|---|---|
| **两层循环分工清楚** | 外层"换一个数 `x`"，内层"试除找因子" |
| **`isPrime` 放在外层循环体里面** ✅ **关键点** | 每换一个 `x` 都要**重新假设它是素数**。要是把它写到循环外面，第一次被改成 0 之后**永远回不来**，后面所有数都会被判成"不是素数" |
| `int i;` 也写在循环体里 | C99 合法，作用域只在本次循环（写外面也行，只是没必要） |
| `2` 能正确输出 | 内层 `i=2; i<2` 一次都不进 → `isPrime` 保持 1 → 输出 ✅（"默认成立"的写法在这里刚好兜住） |
| 注释掉的 `scanf` 留着 | 不影响编译（**注释不是代码**）。等要改成"输入一个数判断"时放开就行 |
