# L07 语句的分类（五种语句 + 控制语句）

- 日期：2026-09-15
- 来源：我自己用 VS 学的笔记 + 鹏哥课件 12.5「控制语句」
- 标签：`#C语言` `#基础语法` `#语句`

> **一句话总结**：C 的语句一共 **5 类**——**空语句**（就一个 `;`）、**表达式语句**（表达式 + `;`）、**函数调用语句**（函数调用 + `;`）、**复合语句**（一对 `{}` 括起来的一块）、**控制语句**（管流程的，共 9 种，分 3 类）。**`;` 是语句的句号，但 `;` 本身也是一条合法语句——这就是最坑的地方。**

## 1. 五种语句，一个一个看（都实跑过）

| # | 语句类型 | 长什么样 | 例子 | 备注 |
|---|---|---|---|---|
| 1 | **空语句** | 一个孤单的 `;` | `;` | 合法，但**啥也不干** |
| 2 | **表达式语句** | 表达式 + `;` | `a = 3;`　`a++;`　`a = a + 1;` | 最常见的一类 |
| 3 | **函数调用语句** | 函数调用 + `;` | `printf("hi\n");` | 本质是表达式语句的特例 |
| 4 | **复合语句** | 一对 `{}` 括起来的一块 | `{ int b = 100; printf("%d", b); }` | 里面几条都行，**0 条也行** |
| 5 | **控制语句** | 见下一节 | `if (a == 4) { ... }` | 管程序怎么走 |

**实测输出**（我写的测试程序）：

```
1) 三种语句跑完了，a = 5
2) 我在复合语句里面，b = 100
3) if 判断成立，a 确实是 4
```

> 注意复合语句的一个特性：在 `{ }` **里面**声明的变量（如 `b`），**出了 `}` 就不认识了**。这就是"作用域"，学到函数时会重点讲。

## 2. 控制语句（鹏哥课件 12.5 原文）

![[L07-控制语句课件.png]]

课件原文要点：

- **控制语句用于控制程序的执行流程**，以实现程序的各种结构方式
- C 语言支持**三种结构**：**顺序结构、选择结构、循环结构**
- C 语言有**九种控制语句**，分成**三类**：

| 类别 | 名称 | 有哪些 |
|---|---|---|
| 1 | **条件判断语句**（也叫分支语句） | `if` 语句、`switch` 语句 |
| 2 | **循环执行语句** | `do while` 语句、`while` 语句、`for` 语句 |
| 3 | **转向语句** | `break` 语句、`goto` 语句、`continue` 语句、`return` 语句 |

**数一数**：2 + 3 + 4 = **9 种** ✔ 跟"九种控制语句"对得上。

> 🔎 **划重点**：`return` 也算**控制语句**（它属于"转向语句"）！我们前面写的 `return 0;` 原来一直在用控制语句——它管的就是"流程往哪儿走"（直接闪出函数）。

## 3. ⚠️ 空语句的经典大坑（我实跑演示了）

空语句最坑的地方：**它会偷偷当 `if` / `while` 的"身体"**。

```c
int x = -5;              // 故意给个负数，让 x > 0 不成立

if (x > 0);
    printf("4) 但这行还是执行了！\n");

if (x > 0)
    printf("5) 这行才真属于 if，不会执行\n");
else
    printf("5) 补充：else 分支执行了 -> 证明上面那个 if 是空壳\n");
```

**实测结果**（`x = -5`，条件明显不成立）：

```
现在 x = -5, x > 0 是不成立的
4) 但这行还是执行了！因为 if 的身体是那个分号
5) 补充：else 分支执行了 -> 证明上面那个 if 是空壳
```

**原理**：

```c
if (x > 0);        ← 这个分号就是 if 的"身体"（一条空语句）
    printf(...);   ← 这行其实【不属于 if】，它永远执行
```

- `if` 后面那个 `;` 被当成了 if 的**唯一一句话**，而这句话是"啥也不干"
- 下面那行 `printf` 缩进了、看着像 if 管着它，**其实一点关系都没有**，永远执行
- 第二个 `if` 没有多余分号，所以它的"身体"是 `printf`，条件不成立就跳到 `else`——**`else` 执行了，反过来证明第一个 `if` 是空壳**

> 比方：`if (x > 0)` 是"如果下雨"，后面那个 `;` 就是**"那就……（啥也没说）"**。你又另起一句"我要带伞"，那句伞跟"下不下雨"没关系了，天天带。

**写代码的规矩**：`if` / `while` / `for` 后面**永远不要单独留一个 `;`**，宁可写 `{}`（空复合语句），至少一眼看得出"这里故意是空的"。

## 4. 现场翻车记录（我自己的）

我在写上面这个测试程序时，字符串里用了**中文引号**：

```c
printf("...if 是"空的"\n");     // ❌ 中文引号把字符串截断了
```

编译器立刻报错：

```
error: expected ')' before '\U00007a7a\U00007684'
```

（`\U00007a7a` = 汉字"空"的 Unicode，编译器看不懂这堆东西）

改成不带引号的说法就好了。**这就是 L01 那条铁律的现实版：字符串里面可以有中文，但符号必须是英文的**——双引号尤其危险，因为在字符串里面 `"` 就是"结束"的意思。

## 7. 嵌入式视角

- **`while(1)` 就是单片机主循环**——它是控制语句（循环执行语句），单片机程序"永远不停"就是靠它。配合 `return` 永远不执行，这也是为什么单片机的 `main` 里通常看不到"程序结束"。
- **`break` / `continue`** 在处理串口数据、按键扫描时天天用（收到结束符就 `break` 跳出接收循环）。
- **空语句的坑在嵌入式里更致命**：`while (!(REG & 0x01));` 这种"空循环等标志位"是**故意**用空语句的写法——所以你必须先认得空语句，才能分清"故意等"和"写漏了"。
- **`switch`** 在解析协议命令字（0x01 点灯、0x02 关灯……）时是标准写法。
