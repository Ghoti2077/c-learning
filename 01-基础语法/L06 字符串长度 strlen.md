# L06 字符串长度：strlen（顺便搞清 strlen 和 sizeof）

- 日期：2026-09-15
- 来源：我自己写在 VS 代码注释里的笔记 + 截图
- 标签：`#C语言` `#基础语法` `#字符串` `#strlen`

> **一句话总结**：`strlen("abc")` = **3**，它数的是 **`\0` 之前有几个字符**（不含 `\0`）；而 `sizeof("abc")` = **4**，它算的是**总共占几个字节**（含 `\0`）。**一个数"内容"，一个量"占地面积"。**

```c
}
```

## 1. strlen 干什么

**strlen = string length（字符串长度）**，它干一件很单纯的事：

> **从一个字符串开头数起，数到 `\0` 为止，看数了几个。**（`\0` 自己不算）

```c
strlen("abc")   →  3    数了 a b c
strlen("")      →  0    空字符串，第一个就是 \0，一个都没数到
```

**实测**：

```
strlen("abc") = 3
strlen("")    = 0
```

## 2. ⚠️ 它住在 `string.h`，不是 `stdio.h`

| 头文件 | 管什么 | 里面的函数（举例） |
|---|---|---|
| `stdio.h` | **input/output** | `printf`、`scanf` |
| `string.h` | **字符串**（string） | `strlen`、`strcpy`、`strcmp`… |

所以用了 `strlen` 就必须：

```c
#include <string.h>
```

**忘了它** → 编译器会警告 `隐式声明`，或者报 `无法解析的外部符号`（链接错误）。**"这个函数住哪个头文件"想不起来时，直接按 F12 跳到声明处看一眼最上面就行。**

## 3. strlen vs sizeof（新手必混的一对）

**实测对比**：

| 写法 | `strlen` | `sizeof` | 差在哪 |
|---|---|---|---|
| `"abc"` | **3** | **4** | sizeof 多算了末尾的 `\0` |
| `""` | **0** | **1** | 空字符串也有 1 格 `\0` |

> 比方：
> - **`strlen` = 数车厢**（有几节有用的车厢）
> - **`sizeof` = 数整列火车的占地面积**（连最后一节"挂钩/句号"车厢也算）
>
> 记住 **`sizeof` 永远比 `strlen` 大 1**（针对字符串）；差的那 1 就是 `\0`。

再对照 [[L04 字符串与结束标志]] 里的结论：`char arr2[] = {'a','b','c'}` 只有 3 格、**没有 `\0`**，所以对它用 `strlen` 会一路数到内存里碰到 0 为止（一个野长度，很危险）。**`strlen` 要能正确工作，前提是字符串里真的有 `\0`。**

## 4. 为什么需要 strlen

因为**字符串自己不知道自己是多长**。`printf("%s")` 只能靠 `\0` 摸黑往前走，而 `strlen` 是**提前数清楚**：

- 要按长度发数据（串口发 20 个字节）
- 要算缓冲区够不够（后面学数组/指针时天天用）
- 要判断"用户输入的名字太长没有"

## 6. 复习题（先自己答）

1. `strlen("hello")` 等于几？`sizeof("hello")` 等于几？为什么差 1？
2. 用 `strlen` 需要 `#include` 哪个头文件？
3. 下面哪一句**能**正确数出长度？为什么另一句危险？
   ```c
   char a[] = "hi";
   char b[] = {'h', 'i'};
   strlen(a);
   strlen(b);
   ```
4. `strlen` 和 `sizeof` 用一句大白话，各自在"数什么"？

> [!question]- 参考答案（先自己答完再点开）
>
> 1. `strlen` = **5**，`sizeof` = **6**。差 1 是因为 `sizeof` 把末尾的 `\0` 也算进"占几字节"了，而 `strlen` 只数 `\0` 之前的字符。
> 2. **`#include <string.h>`**（`stdio.h` 只管 printf/scanf 这类输入输出）。
> 3. `strlen(a)` **能**，因为 `"hi"` 末尾有双引号自动补的 `\0`，数到它就停，答案是 2。`strlen(b)` **危险**——`{'h','i'}` 没有 `\0`，`strlen` 会一直往后数（越界读），得到一个随机长度。**没有 `\0` 的字符数组，不能当字符串用。**
> 4. `strlen` 数**内容有几个字符**（不含 `\0`）；`sizeof` 量**这块东西一共占几字节**（含 `\0`）。

## 7. 嵌入式视角

- **串口/协议解析**：收到一包数据后要判断"有效数据几个字节"，就是 `strlen` 的活；而"缓冲区多大"要看 `sizeof`。**两个都不能搞错**——用 `sizeof` 当长度发数据，会把末尾的 `\0` 也发出去，对方收到就多一个怪字符。
- **缓冲区永远要多留 1 格给 `\0`**：收 10 字节字符串 → 数组开 **11**。
- **`strlen` 是"跑一遍"的函数**（要一个字符一个字符数到最后），数据长的时候慢。在**中断服务函数里别调 `strlen`**，这是嵌入式里很常见的性能坑。
